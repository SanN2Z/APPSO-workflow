# Fable 5 一小时搭个 Agent，够换 DeepSeek 内测门票吗？

看到 LinearUncle 说要让 Fable 5 花一个小时现场写一个，我的第一反应也是：我也想现场搭一个。可 DeepSeek Harness 团队成员 Tianyi Cui 给出的报名门槛很具体：做过 Agent Harness 相关开源项目，附上 GitHub ID 和开源代表作，再回复或私信联系。

这个玩笑好在把两只钟挤到了一起。一只是「从空目录到代码跑通」的开发时钟，生成代码越快，它转得越快；另一只是「系统在长任务里究竟会怎样坏」的运行时钟。后者要等上下文变长、工具接连调用、权限发生冲突、失败触发重试，才会慢慢露出刻度。Fable 5 可以压缩前一只钟，却很难替第二只钟走完路。

## 第一次跑通，只是启动了第二只钟

假设一个小时足够生成 Agent 循环、接好几个工具、补上状态存储和重试，再让示例任务顺利完成，这当然有价值。它把想法变成了可执行的假设：工具接口能不能连上，基本流程是否闭合，人在什么位置介入。很多明显的设计错误，也会在第一次运行时被抓出来。

Harness 真正难缠的部分，却常在「每个零件单看都正常」之后出现。它要持续决定：这一轮该保留哪些上下文，工具失败能否重试，重试前的环境是否已经改变，权限拒绝意味着换条路还是立即停下，最后又凭什么认定任务完成。这些判断彼此相连，前面一次很小的偏差，可能在十几步以后才变成可见结果。

DeepSeek-V4-Flash-0731 的官方模型卡已经把这层运行系统写进评测脚注：公开基准里的 Code Agent 任务使用待发布的 DeepSeek Harness minimal mode，并列出 max reasoning effort、temperature 1.0 和 top_p 0.95。这个事实只能说明 Harness 参与了那套评测条件；它没有告诉外界 Harness 单独贡献了多少，也没有披露产品形态与测试协议。随后出现的定向内测邀请，恰好把问题推向了运行现场：一套框架被更长、更杂的任务折腾时，会留下什么样的错误？

## 一处权限错误，怎样变成「任务完成」

想象一个具体任务：Agent 要在一个陌生仓库里改动接口、补测试、运行检查，同时遵守「不要修改构建配置」的限制。它读完需求，查找文件，完成第一轮修改。到了第九次工具调用，测试要写入临时目录，却被权限策略拦住。

Harness 看见非零退出码，按预设自动重试。为了给新增日志腾出上下文，它压缩了较早的信息；摘要记住「测试尚未通过」，漏掉了「不要修改构建配置」。Agent 于是把失败理解成环境依赖问题，改了配置，再次运行测试。第二次命令又因为工作目录变化，只执行了一个较小的测试集合，最终返回成功。验收环节只看见退出码为零，便把任务标成完成。

此时没有哪个动作显得荒唐：权限拦截保护了环境，重试试图恢复任务，上下文压缩节省了窗口，测试命令也确实成功。它们串在一起，却造出一次「假完成」——限制被破坏，完整检查没有执行，成功信号仍然出现。这里写的是一条假想故障链，不是 DeepSeek 已披露的架构；它说明的只是 Harness 的长尾为何来自组合，而不只来自某一行代码。

要修这类问题，开发者得先保留整条轨迹：压缩前后丢了什么，失败时哪些文件已经改变，重试是否重复了有副作用的动作，验收有没有重新读取最初约束。接着还要复现、改规则、重跑，再观察新护栏会不会卡住原本正常的任务。一步可以快速生成，故障组合何时出现却无法预先下单。你可以在一小时内写几项故障注入测试，却很难在同一个小时里获得「哪些意外最值得注入」的真实分布。

这也是开源代表作可能提供的信息：开发者遇见过哪些反例，怎样记录一次失败，为什么选择停止而非重试，又拿什么证明确实修好。DeepSeek 没有公开解释筛选动机；寻找高质量 bug、比较不同架构经验或发现人才，都只能算可能性。可以确认的只有申请材料本身，以及这不是一张只填邮箱的普通候补表。

## 一小时之后，手里应该有什么

真要响应那句玩笑，一小时并非白费。它足够搭出一个能跑的原型，也足够提前埋下记录点：保存每次上下文压缩的差异，记录工具参数与权限决定，给重试标注原因，让验收展示实际执行了哪些检查。还可以故意制造一次超时或权限拒绝，看看状态能否回到一致位置。这样得到的仓库，至少开始提出可检验的问题。

它仍然没有替系统经历长任务。你还没有看到第九次调用留下的状态怎样影响第二十次调用，没有证明恢复策略在重复运行后仍有效，也不知道某条安全限制会不会逼出新的绕路。一次漂亮演示提供的是起点和假设；反复出现、可以复现、修完后还能重新验证的边角故障，才需要运行时钟亲自走过。

所以，一个小时能得到代码骨架、第一次成功和一组准备追问的问题；一个小时得不到被真实任务反复折腾过的轨迹，也得不到对恢复与验收边界的确信。Fable 5 可以把第二只钟迅速拨到起点，余下那些只在长任务里出现的刻度，仍要一格一格走出来。
