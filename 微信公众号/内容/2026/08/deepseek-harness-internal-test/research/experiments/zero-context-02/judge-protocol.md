# EXP-002 匿名配对评审协议

你不知道 A、B 的分支身份，也不得寻找 mapping、写作者提示词、编译计划、旧稿或外部网页。先连续读完两篇候选正文，再读冻结材料核查。不要给总分。

## 要判断的不是「谁写得更漂亮」

请比较：

1. 必要顺序：哪篇的后一段更像由前一段产生的问题逼出来？指出一处最强连接，并尝试交换一组相邻段落。
2. 材料取舍：哪篇更敢丢掉不服务核心问题的跑分、项目名单和背景？指出每篇最可删除的一段；若没有，写「无」。
3. 公共价值：合上文章后，普通读者能否准确说出「为什么门票先发给同行」以及「这件事目前不能说明什么」？
4. 推断纪律：哪篇把作者解释留作解释，没有把招募动机、厂商战略或产品形态写成事实？
5. 具体记忆：分别为 A、B 写下你实际记住的 2 个事实、1 个作者推断、1 个未知项。写不出时不要补。

## 重大事实阻断项

逐篇检查：

- 把厂商自报跑分写成第三方结论；
- 把「to be released」写成已经发布或开源；
- 补写材料没有的产品形态、时间、价格、人数或测试协议；
- 把第三方项目写成已入选或官方合作；
- 把推测动机写成 Tianyi Cui 或 DeepSeek 已确认的说法；
- 把 LinearUncle 玩笑当关键证据。

## 强制结论

最后只能选择：

- A
- B
- 平局

平局只用于确实无法给出结构性偏好，不能因为两篇都合格就回避选择。给出高／中／低信心，并用一句话说明：赢家究竟在哪个「材料变成阅读路径」的动作上更好。若只是更喜欢语气，必须判平局。

输出文件按以下标题：

1. 「正文初读」
2. 「必要顺序与删节测试」
3. 「事实、推断与未知项回忆」
4. 「事实护栏」
5. 「选择」
