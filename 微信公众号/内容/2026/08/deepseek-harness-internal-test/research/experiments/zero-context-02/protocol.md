# EXP-002｜乱序弱场景材料的零上下文配对实验

冻结时间：2026 年 8 月 2 日（UTC+9）

## 要回答的问题

当题材缺少天然强场景、来源又被故意打乱时，在现行内容工作流 v4.0 前增加一个压缩后的「文章编译器 0.2」，能否让首稿更会删材料，并形成更难任意换序的阅读路径？

本轮只检验这一项生产机制，不检验 AI 检测器分数，不证明哪种写法普遍更像人，也不修改正式 SOP。

## 冻结输入

- 题目：DeepSeek 自研 Harness 开内测，门票先发给同行
- 读者：知道大模型和 Agent，但不开发 Agent 框架的普通科技读者。
- 读者问题：为什么 DeepSeek Harness 的内测先找做过开源 Harness 的开发者？这件事目前能说明什么，又不能说明什么？
- 文体：900—1600 个中文字符的公众号观察稿；允许 2—4 个小标题；不是逐条播报，不凑成长篇。
- 材料：仅可使用 source-packet.md。材料卡顺序由 SHA-256 规则生成，顺序不表达时间、重要性或推荐结构。
- 共同规则：两分支都执行下文冻结的 v4.0 摘要、事实硬门与停止标准。
- 模型与运行时：同一会话树、同一模型家族、相同 reasoning 配置；写作者均使用 fork_turns:none 的隔离 Session。
- 人工分钟：本实验没有人类写作者，无法得到可比的人类操作时长，预先固定为 null，不用 Agent 墙钟时间代替。

## 现行 v4.0 摘要

两位写作者都必须执行：

1. 自由判断：先判断材料是否值得写、对公众的具体价值是什么；材料不足时缩短，不靠修辞制造宏大主题。
2. 编辑取舍：正文只兑现一个承诺，首屏出现压力，一条叙事发动机贯穿；材料之间要有关系，不按来源类别排章节。
3. 硬门检查：数字、日期、身份、产品状态和引语只能使用冻结材料；事实、厂商自报、作者判断和未知项分开；不把边界澄清扩成无人关心的独立章节。
4. 中文使用「」；中文与英文、阿拉伯数字之间保留半角空格。

## 分支

- 对照：只使用上述 v4.0 摘要与冻结材料，自行规划后直接成稿。
- 干预：使用相同规则与材料，但成稿前必须完成 compiler-instructions.md 中的文章编译器 0.2；计划不超过 800 个中文字符。
- A／B 身份只记录在 mapping.yml。盲审完成前不得揭盲。

## 共同交付

每位写作者交付一份 candidate：

1. 先给完整正文，不写实验说明。
2. 正文后加入 HTML 注释标记「FACT MAP」，列出实际使用的材料卡 ID、文章中的作者推断和保留的未知项。
3. 不生成图片，不调用网页，不读取同内容包的旧稿、brief、sources、review、retrospective、选题卡、实验映射或另一分支。
4. 不为通过 AI 检测器而故意改写。

干预分支另交一份 compiler-plan，正文前不得把计划内容写成解释。

## 主指标

指标名：blind-pairwise-preference

两名相互独立的零上下文评审只看到匿名 A、B 正文、冻结材料和 judge-protocol.md。每人必须选择 A、B 或平局，并给出信心。

优先比较：

- 哪一版的后一段更像被前一段逼出来，而不是可以随意换序；
- 哪一版更敢丢掉不服务读者问题的背景；
- 哪一版给普通读者留下更具体、可复述的认识；
- 哪一版更少从碎片中制造厂商战略、产品形态或宏大结论。

## 冻结判定

- supports：两名评审都选择干预分支，信心均不低于中；干预分支没有更多重大事实阻断项；compiler-plan 不超过 800 个中文字符。
- neutral：评审分裂、任一评审选平局、干预只在语言偏好上获胜，或计划长度门未通过但没有事实倒退。
- contradicts：两名评审都选择对照分支，或干预出现对照没有的重大事实越界。

同一案例中的两名评审只提高判定稳健性，不算两个独立内容案例。本轮无论结果如何，最多形成 E1，不能单独触发正式 SOP 修改。

## 事实护栏

- DeepSeek 跑分只能写成官方模型卡自报，并保留评测条件。
- 「to be released」不等于已经开源或已经正式发布。
- 内测邀请不等于产品发布，不得补写名称、界面、发布日期、价格、开放方式、首批规模或测试协议。
- 招募开源开发者可能有多种解释；动机只能写成推断。
- 第三方项目只说明候选报名者可能带来的经验类型，不代表它们已入选，也不代表 DeepSeek 的产品定位。
- LinearUncle 的帖子只可作为已标明来源限制的评论性开场，不可作为关键事实。

## 停止标准

两份候选稿、两份独立盲审和揭盲结果全部固化后停止。结果只写回实验目录与 INSIGHT-001；不覆盖当前正式稿，不发布，不排版，不生图，不接入检测网站。
