## 冲突与未知项

- 豆包官方帮助页确认「更多免费服务额度」，但未在当前文本中写出 2.5 倍。2.5 倍来自 8 月 12 日媒体对豆包公告的转述，正文必须保留厂商归属。
- Google 新公告页可以确认美国和海外方案差异；资格与自动续费只采用 8 月 19 日更新的条款。中国大陆不在当前 AI Plus 支持名单，不提供领取建议。
- 腾讯云 HAI 页面部分价格由前端动态加载。只写「半价券」和可稳定读取的面额、有效期，不自行反推结算价。
- Perplexity、GitHub、OpenAI Codex 属于仍在生效的长期或早前权益。它们只作「现在能领什么」的背景，不并入「本周集中发布」表述。
- GitHub 学生包和 Azure 权益是当前公开页面列出的合作项目，不保证每所学校、每个地区都能通过验证。正文只写当前权益和实际验证限制。
- HAI 的「关机不计费」只停止算力费。云盘仍有独立规则，正文明确区分关机与销毁，避免把优惠写成完全零成本。
- DeepSeek Harness 仍处于 developer preview。正文只把它作为理解 Agent 工具、上下文和工作步骤的进阶热点，不把它列为本科生第一款稳定工具。
- DeepSeek 配合 Claude Code 仍需安装工具、配置 API Key 并承担实际 API 用量。正文不得把它写成免费会员或学生权益。
- Prism 免费范围、账号范围和项目协作者数量采用 OpenAI 现行公告与帮助页。中国大陆不在当前支持地区名单，正文不提供绕行建议。
- AIM Review 的论文已通过 Nature 页面与 Crossref DOI 记录核对。正文只介绍工作流，不引用论文中的节省比例或分类准确率。
- 中国科技云公开资料确认三项免费服务，但普通高校师生的权限仍不清楚；正文保留「登录后以实际显示为准」。
- ChatGPT for Academic Researchers 已进入候补阶段。10 万人为计划规模，不写成当前已经发放 10 万个账号。
