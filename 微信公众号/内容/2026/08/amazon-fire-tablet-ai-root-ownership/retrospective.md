## 因果复盘

```text
事实已经足够，但段落后继续补解释和总结
→ 故事推进变慢，结论出现多次
→ 写作阶段把每段都当成需要单独收束的单元
→ 保留事实和顺序，只删除重复解释与用力收尾
→ 修订稿冷读、开头检查和内容包验证
→ 本轮沿用既有规则 `PROJECT-WECHAT-EXPLANATION-001`，不新增 SOP

素材已经下载，但只有 1 张图进入正文，且使用了通用风格
→ HTML 预览无法反映最终图片节奏，既有视觉识别也丢失
→ 执行时没有把「进入 draft + manifest + 最新预览」作为同一个交付单元
→ 按 6 张正文图重新分配点位，AI 图统一走 `clumsy-doodle-v1`
→ 核对图片计数、preflight、原尺寸、手机宽度和最新 HTML
→ 既有 Image2 SOP 已覆盖该失败，不新增中心规则

网友评论被重新排成项目卡片
→ 用户拿不到平台原貌，还需要追问是否存在真实截图
→ 把「评论配图」理解成了可读引文，而不是平台证据
→ 从 HN 原页按评论 ID 截取评论节点，只裁切，不改网页内容
→ 核对原图、清单、正文路径、旧卡残留和最新预览
→ 本案例保留，不把所有引用卡一律改成截图
```
