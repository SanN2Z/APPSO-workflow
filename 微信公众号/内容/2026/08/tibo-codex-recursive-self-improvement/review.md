# 独立冷读与修订记录

日期：2026 年 8 月 25 日

## 冷读方法

- 审稿 Agent 第一轮只读取公开正文 `draft.md`，未读取 brief、sources 或研究记录，也未编辑文件。
- 第一轮先定位问题，逐项给出读者损失、原因与通过条件。
- 第一轮报告完成后，审稿 Agent 才读取 `brief.md`，判断哪些问题需要改合同、哪些可以局部修复。
- 写作者接受问题后重做章节依赖；同一审稿 Agent 再按原通过条件验收修订稿。
