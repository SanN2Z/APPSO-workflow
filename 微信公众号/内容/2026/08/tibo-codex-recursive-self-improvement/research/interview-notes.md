## 7:31—14:00｜为什么今天的 Codex 会显得原始

- 主持人复述原帖：现在的 Codex 是一套不错的 harness，但两三个月后会显得原始；下一代模型需要的资源超过一台笔记本电脑。
- Tibo 说，今天最熟练的 coding-agent 用户仍在容忍许多笨重之处：手工维护 skill 文件，记忆并不完整，多 Agent 网络会暴露产品拼接感。
- 他期待的产品能深入理解用户、目标、日常工作和团队，并在合适时机主动行动。
- 笔记本电脑和传统软件围绕人的注意力与操作吞吐设计；模型可以同时处理远多于人的应用和任务，因此未来 Agent 的计算与交互不应被一台笔记本框住。
- 多 Agent 并发会把瓶颈从模型能力推向人的注意力。主持人以同时启动 10—15 个 Agent 后频繁切换为例，Tibo 随后强调超快响应、语音和保持 flow 的重要性。
- 他区分两类前景：深度个人化、与人连续协作的 Agent；以及对复杂流程的自动化，例如生产日志、性能回归和安全扫描。

## 30:25—32:05｜Tibo 怎样使用 RSI 这个词

- 主持人将「模型参与训练或优化下一代模型」以及 Sol 优化 Luna 等内部工作与早期 RSI 联系起来。
- Tibo 先承认，RSI 最常见的用法是研究和模型开发其他模型。
- 他随后扩大系统边界：OpenAI 也在用模型开发运行和使用这些模型所必需的关键基础设施；如果把这些部分视为一个整体，这同样是一种 RSI。
- 他列举的系统层包括前端栈、硬件内核、新产品与界面、云端 Agent。核心动作是把系统「指回自身」。
- 他没有在这段话里声称 OpenAI 已经实现能自主设计、训练和验证更强继任模型的完整闭环。
