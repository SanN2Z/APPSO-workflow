# 社区反应取证

取证日期：2026-08-26（Asia/Tokyo）。本页记录的是定向样本，不代表总体舆情。互动量只按各平台页面可见口径保留，不跨平台换算或混排。

## 选帖方法：双轨而非唯热度

- 「热度证据」：互动量明显，能证明真实需求或真实摩擦确实存在。
- 「讨论惊喜」：互动量达到可见门槛但未必最高；观点具体、少见，能够把文章带到新的问题。
- 候选还需满足：与主论点直接相关、原帖上下文可核、短摘录足够表达、隐私与权利风险可控。

- 「101」「10」「7」是 2026-08-26 取证时的页面可见值，之后可能变化。
