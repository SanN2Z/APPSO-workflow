## 因果复盘

```text
官方公告与帮助页对 Chat/Cowork 记忆边界存在冲突，且发布后社区样本很少
→ 若直接按公告写成普遍可用或按零散帖子写成社区共识，读者会误判 rollout 与真实口碑
→ 新功能发布、文档更新和账号 rollout 不同步；早期社交反应缺少使用时长
→ 正文保留对象级归属、帮助页冲突和 8 个待实测位；社区段落明确为定向抽样
→ `tools/workflow.ps1 validate` 通过；开场检查通过；事实卡区分厂商自报、第三方结果和作者判断
→ 适用于本次上线初期稿件；若后续有大样本调查、官方故障说明或作者复现，应以新证据更新
```
