## 因果复盘

```text
事实链和章节方向可用，但正文过度解释、若干段落合并过长，结尾判断也比用户版本更用力
→ 读者需要穿过更多编辑旁白才能抵达问题本身，手机端节奏偏慢
→ AI 初稿在证明论证完整时加入了重复转折和总结，且没有充分让短段落承担推进
→ 用户重写为更短的段落，拆开法律动作与裁定边界，结尾回到「谁判断、谁使用」两个具体问题
→ `draft.md` 的可见正文与用户提供文本一致，来源编号以文末定义保留
→ 只证明这篇 APPSO 稿的具体表达偏好；尚不足以推广为跨题材规则
```

```text
市场影响和公共可访问性只停留在结尾追问
→ 读者理解了「公司为什么拆书」，却未必看见实体副本退出流通与内部数字副本不公开的具体后果
→ 初稿把产业机制当成主线，把读者侧后果误判为一句结尾即可承载
→ 用户新增两个完整章节，分别写大宗买家的购买特征与「数字化不等于公众可访问」
→ 新版正文、S11 来源映射和两张独立示意图已经落包；数量表述仍保留事实阻断项
→ 属于本稿的结构补全，是否形成 APPSO 通用要求仍需更多案例
```

```text
配图全部由 AI 生成，机制解释清楚但缺少报道现场感
→ 读者看见了编辑解释，却不容易感知调查报道、书商采访和跨媒体跟进确实存在
→ 首轮把「不冒充证据」理解成只做示意图，没有同时配置明确归属的证据型截图
→ 用 404 Media、《卫报》和《The Atlantic》的有限页面截图承担来源触感，AI 图只承担扫描、数据循环、内部资料库和保存选择
→ 截图均保留媒体标识和页面语境，并在图注与清单中完成归属和用途登记
→ 先作为本稿视觉修订保留；是否推广为 APPSO 调查稿默认配图比例，继续观察更多稿件
```

```text
事实与数据充分，但分析型长稿只在当代材料内部来回解释
→ 文章容易准确却缺少文化记忆和人物触感，抽象机制也不容易被读者记住
→ 研究阶段没有主动寻找能解释同一关系的经典作品、作家经验或思想史文本
→ 先用现实证据建立事实，再用 0–2 个可核出处的文化参照命名机制、提供类比或改变观察尺度
→ 用户样本中的本雅明对应「复制到生成」、阿多诺与霍克海默对应「标准化文化商品」；产品更新快讯作为不触发的反例
→ 这是用户明确指定的 APPSO 项目偏好，按 E0 项目配置执行，不宣称为通用写作定律
```

## 经验分级

### 仅保留在本案例

- 本稿采用用户提供的逐段表达，尤其保留法律段的拆分方式与两问式结尾。
- 本稿把旧书市场变化和数字副本可访问性拆成两个独立章节。

### 继续观察

- APPSO 长稿是否应优先用短段落承担论证推进，减少「所以」「这也意味着」式解释性桥接。
- APPSO 调查型长稿是否适合默认采用「报道截图提供证据触感、原创示意图解释机制」的混合视觉结构。

### 项目配置

- `APPSO-CULTURAL-ANCHOR-001`：分析型长稿在素材阶段主动寻找可核出处的文化参照，正文按需使用；经典负责解释机制，不负责证明当代事实。

### SOP 候选

- 暂无可迁移 SOP；本轮只配置 APPSO 项目 adapter，不修改通用工作流。
