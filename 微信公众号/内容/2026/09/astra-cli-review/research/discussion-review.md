# Astra 讨论与测评补充

调查日期：2026-09-05。这里只归纳已看到的材料，所有来源 ID 对应 sources.md。

## 最适合这篇测评的几条线索

**审美、写作变好，但是否懂产品仍有分歧。** Every 的公开导语肯定写作、软件操作和视觉设计，同时认为 Fable 的产品构建直觉更好。作者称 Astra 从单条提示写出的初稿曾被同事认作本人写作。全文付费，当前无法核验具体样本与控制条件。这支持我们单独测试视觉和写作，不支持提前写「Astra 文笔已经超过人」。S07。

**工程交付比代码量更值得看。** Cognition 在自有 FrontierCode 1.1 中称 Astra 超过 Fable 5.1、略低于 Fable 5，且在 Devin 的测试任务上改善报告和视频证据。其说明明确评分看质量和可合并性，不是生成文件数。这是集成合作方测评，适合启发 C03 的验收设计，不能推广成所有代码库结论。S06。

**运行框架会实质影响成绩。** ARC Prize 同时提供通用接口和厂商适配接口的结果，显示上下文状态的保存方式影响任务完成。这一差异值得在稿中用一句话和一张原图交代，避免把「Codex 实际体验」误包装成纯模型智力横评。S05。具体数字见 sources.md，不重复铺满正文。

**Astra 也有额度摩擦，不能先假设它更省。** Reddit 同一首发串里既有人抱怨高档推理很快触顶，也有人说相同任务 Token 下降。没有一致的套餐、工具、提示词与难度，不能统计为故障率或平均省额比例。S09。因此，Astra 与 Fable 两边均记用量与失败；Fable 只跑 C02。

**专业能力确有外部直接测试，但不必拿来当本篇主轴。** Irregular 在与 OpenAI 合作的评测中，FrontierCyber 完成数从 GPT-5.6 Sol 的 34／226 升至 Astra 的 86／226，两者都未解 Elite 题。其浏览器案例关闭了内容沙箱，机构也未据此声称攻破完全加固系统。这是一条有方法限制的外部证据，本篇不将其转成攻击题。S08。

## 没有当成实测证据的内容

- 发布前「10T 参数所以肯定贵」等帖子：时间和证据不足，不适合解释发布后的实测用量。
- DataCamp 等搜索结果中的发布介绍：能帮助找线索，但不替代测试者原文或官方表。
- Matthew Berman 的视频摘要聚合页：看到演示线索，但未完整核验原片与各段原始任务，暂不借二手摘要写成详细实测结论。
- Every 付费正文：当前只读到公开部分，没有绕过付费访问，也没有据摘要扩写未读内容。

## 暂定可证伪问题

Astra 是否能把视觉和写作的第一印象，继续维持到可用功能、精确修改和完整交付？如果 C02 漂亮但购物袋错、C01 改短后丢失反面事实、C03 修补造成新错误，正文必须相应收窄「能交付」的判断。若表现稳定，也只写本次案例和配置，不推断全天自主工作。
