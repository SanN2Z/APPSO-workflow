# 小妖快跑：鬼门关淘汰赛

给 Astra 和 Fable 5.1 各开一个独立空文件夹，分别启动 CLI，粘贴下面同一段即可。无需 records.json，不需要旧 C02 唱片店材料。本任务先各做一次，不预设模型胜负。

```text
帮我做一个能在浏览器里真正玩的 3D 小游戏，叫「小妖快跑：鬼门关淘汰赛」。玩法像糖豆人的障碍闯关，但场景是壮观的中式神话世界。

我要的第一眼是：巨大的青铜鬼门关悬在云海里，断裂石桥连向远方，朱红灯笼、古老石像、冷青色雾气和金色门缝形成强烈反差。场景要有远近层次、好看的光影和材质。宏大的建筑脚下，是一群圆滚滚、跑起来摇摇晃晃的小妖，气势很大，摔起来很好笑。

玩家操控一个提着小灯笼、急着下班的小鬼差，和 5 个电脑小妖一起闯关。做一条完整赛道就好：躲过钟摆石桥，跳过旋转八卦台，抓准时机穿过开合的鬼门。WASD 移动、空格跳跃，镜头平滑跟随；被撞飞或掉下去能很快从检查点回来；冲线有庆祝和再玩一次。电脑角色用简单逻辑即可，不做联网多人。

重点把场景做漂亮、操作做顺手，开场就要能看到真正的 3D 游戏世界，别只给一张宣传页。让画面中的尺度、光影和角色动作产生惊喜，别只靠多堆特效。角色和素材自己做，不搬现成游戏的模型、Logo 或音乐。

可以使用 Three.js 和必要的最小依赖，优先利用当前环境，只由你一个 Agent 完成。只操作当前文件夹，不读取其他项目，不下载大型素材包，不调用付费生图或其他模型。先交付一个完整、可玩的关卡，自己启动检查一下；缺少浏览器时说明未验证的部分。给我启动命令，完成后停止，不自行增加地图、账号或商城。
```

先保存首轮并实际玩一下。若出现黑屏、无法起跳或不能过关，再把遇到的具体问题反馈给它做一次局部修复；不用提前安排多轮美术修改。
