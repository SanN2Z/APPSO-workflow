# 原创机械展品：一对齿轮

做一个在屏幕上能观看、能操作的机械展品，主题是「两种速度」。

20 齿主动轮与 40 齿从动轮外啮合；两个轴固定，中心距与节圆半径一致。主动轮顺时针转一圈，从动轮逆时针转半圈。暂停、反转、转速滑杆、复位必须可用；改变转速或反向不能突然跳角。

希望有材质、光影、空间层次，但信息清楚比炫技重要。镜头至少有一个可切换视角；视觉上能辨认两轮齿数不同。可用 Canvas、SVG 或 CSS 3D，不要求工程级渐开线齿形。不要把近似动画称为制造模型或物理仿真。

只用原生浏览器能力，不联网、不依赖 CDN、不安装库、不调用生图。双击 index.html 运行，手机上能操作。
