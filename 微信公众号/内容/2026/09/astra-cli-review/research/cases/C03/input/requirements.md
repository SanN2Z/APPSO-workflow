# 排期工具合同

全部记录是虚构测试数据。

- `conflicts(events)` 返回同一频道内所有冲突对。时间区间为左闭右开，10:00 结束与 10:00 开始不冲突。
- 每条记录有唯一字符串 id、channel、带时区的 ISO 8601 start/end。不同 UTC 偏移必须按同一真实时刻比较。
- 冲突对内部按 id 字典序排列，最终列表也按字典序排列，无重复。
- 必须处理包含关系、非相邻记录、跨午夜、空列表；输入顺序不改变结果；不能修改输入对象。
- end 必须晚于 start，缺少时区或重复 id 均抛 ValueError；两项公开函数都遵守验证规则。
- `total_minutes(events)` 对所有事件各自时长求和，不做并集、不去重。允许大于 24 小时，输入限定为整分钟时间。
- 不更改公开函数名或参数；只用 Python 标准库。
