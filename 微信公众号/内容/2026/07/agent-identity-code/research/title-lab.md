# 标题实验

## 候选

1. AI Agent 开始拿钱包了，中国先给它办「身份证」
2. 你的 AI 替你打车前，先得证明「它是谁」
3. Agent 有了「身份证」，就不会乱来了吗？
4. 当 AI Agent 能花钱，谁来替它签字？
5. 中国给 Agent 定了 7 条规矩，第一条是别冒名

## 当前选择

- 主标题：AI Agent 开始拿钱包了，中国先给它办「身份证」
- 理由：把当周支付热点和身份码建立因果张力，普通读者能在 5 秒内复述。
- 风险：「中国先」可能被理解为国际首创；正文不使用世界首个等比较级，终稿可按用户反馈改为更稳的第 2 个标题。

## 副标题方向

- 身份码能回答「它是谁」，却不能保证它不会犯错、越权或被劫持。
