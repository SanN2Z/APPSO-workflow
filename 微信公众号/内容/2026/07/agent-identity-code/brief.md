# Brief

## 读者与承诺

- 选题：中国发布智能体互联系列标准，Agent 开始拥有「身份码」
- 任务类型：新选题 / 调研 / 写稿 / 配图
- 稿型：时效热点 × AIGC 解释稿
- 目标读者：关注 AI 产品，但不了解标准、协议与 Agent 基础设施的普通科技读者
- 读者已知：Agent 能调用工具、跨应用办事
- 读者盲区：「身份码」到底是什么，和安全认证、实名制、强制监管有什么区别
- 单一主钩子：Agent 开始拿钱包、跨平台办事后，行业必须先回答「它是谁、谁授权、出了问题找谁」
- 一句话承诺：用 7 项标准和两个当周热点，讲清 Agent「身份证」能解决什么、解决不了什么
- 读者看完应带走：身份码是责任基础设施，不是安全合格证；授权、限额、撤销和审计仍需单独建立

## 背景与论点

- 前置极简事实卡：2026 年 5 月 22 日，国家市场监管总局批准发布 `GB/Z 185.1—185.7-2026`；6 月发布会称 50 多家企业正在开展试点；7 月 22 日媒体又报道北京专题会发放首批身份码
- 核心判断：Agent 从回答问题走向调用服务、跨端协作和移动资金后，「可识别、可授权、可撤销、可追责」会变成比拟人化体验更基础的竞争力
- 最强反例 / 替代解释：统一身份也可能增加中心化依赖与数据关联风险；身份真实不等于能力可靠，更不等于行为安全
- 结尾必须完成：给普通用户一张授权 Agent 前的 5 问清单
