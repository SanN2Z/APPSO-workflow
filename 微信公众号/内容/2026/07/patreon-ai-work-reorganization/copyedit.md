## 缺陷记录

### COPY-001 · minor · resolved

- 原句：「Gemini API 的细粒度主分析只纳入了能取得内容的免费请求，付费 API 和企业签约日志没有进入这部分。」
- 问题：「能取得内容」没有显式主体，既可被理解为研究者能取得请求内容，也可被误读为用户通过请求取得内容。
- 最小修复条件：补出「取得内容」的主体，明确这是研究样本的可见性限制；不改变免费 / 付费 API 的事实边界。
- 复检：resolved。新句已补出「研究团队」，并保留了样本可见性限制。

### COPY-002 · minor · resolved

- 原句：「它衡量的是达到使用门槛的任务比例，不是个人工作占比或节省的工时。」
- 问题：代词「它」可以回指前文的「报告」，也可以回指「21%」这个统计值，而后一种才是本句所需的口径。
- 最小修复条件：用明确名词指向「21%」这个统计值，保留后半句的口径限定。
- 复检：resolved。新句已明确改为「这个 21%」。

### COPY-003 · major · resolved

- 原句：「可从草稿到可发布的图，审美取舍、信息准确、细节修改和版权边界一样不会自动消失。」
- 问题：「审美取舍、信息准确、细节修改和版权边界」的词性与语义不平行；「信息准确不会消失」还会被读成准确性不受影响，与本句要表达的「仍需人工处理」相反。
- 最小修复条件：将四项统一为同类动作或名词，并让谓语统一落在「仍然少不了」这层意思上。
- 复检：resolved。新句已将四项统一为人工处理动作，并共用「仍然少不了」。

### COPY-004 · minor · resolved

- 原句：「它可能压低纯检索、搬运和转写任务的预算，再把预算和权限移向问题定义、来源核验和风险处理。」

- 复检：resolved。新句删去了不能共用谓语的「权限」，保留「预算」与任务环节的搭配。

### COPY-005 · major · resolved

- 原句：「至少在 ATLAS 所观察的这批交互里，AI 使用已经进入许多职业的部分任务。一份职业还叫原来的名字，日常的资料流转、协作节点和成本计算也可能已经换了。」
