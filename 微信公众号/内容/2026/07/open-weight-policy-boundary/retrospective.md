## 因果复盘

```text
政策稿只有文字，时间线证据与抽象概念缺少视觉分工
→ 读者难以确认「后来签了」的页面变化，也难在手机端理解 API、开放权重和蒸馏边界
→ 配图若只追求统一风格，会牺牲证据性；若只堆截图，又会牺牲解释性
→ 用 X 截图承担时间证据、官方页面承担产品事实、笨拙涂鸦承担概念解释
→ 7 张图片全部入稿并登记来源、修改、平台和权利状态；校验 0 error
→ 适用于「时间线 + 抽象机制」并存的政策分析稿；单一产品快讯不必机械凑齐三类图片
```

```text
材料按月份、政策文件、公司和影响对象不断扩展
→ 读者能记住事件，却说不清这些事件共同证明什么
→ 时间顺序被误当成论证顺序，政策史遮住了 NVIDIA 与 OpenAI 的商业冲突
→ 将政策降为压力背景，按「反常动作 → 双方利益 → 三项权利 → 学习权」重排
→ 隐去小标题后仍能复述同一条因果链，结尾回到开头提出的两家公司为何共同签署
→ 仅适用于本稿；是否形成跨稿规则，需另一个独立案例验证
```

```text
章节关系已经收紧，但每节仍完整解释编号、案例和授权分类
→ 读者理解了每个知识点，却在人物行动之间频繁停顿，故事再次变成讲义
→ 根因是结构重写后没有同步降低证据密度，仍试图在正文穷尽每一种情况
→ 政策、案例和合同只各保留能推动下一步的一项证据，三项权利改由同一个企业训练场景带出
→ 正文缩至 3 个功能小标题、4 张图和约 2200 个去格式可见字符，长短句与段落详略产生变化
```
