## 因果复盘

```text
标题承诺「撞现实」，初稿却先展开较长模型史
→ 读者可能只记住型号，核心答案出现太晚
→ 写作者先满足历史材料完整性，未先交付核心框架
→ 前置两层答案，再让历史只证明「执行能力正在变便宜」
→ 独立冷审关闭 RELEASE-001—005
→ 适用于双任务深度评论；纯历史稿不必强行前置 loss 框架
```

```text
SOP 记录了固定 Prompt，但调用入口仍允许自由拼装通用封面描述
→ 第一版先命中「成熟科技媒体」模板，固定风格只在用户纠正后才补上
→ 根因不是 Prompt 不够清楚，而是风格路由没有优先级、无参考图没有受控方案、调用前没有可执行检查
→ 把 APPSO adapter 提到通用模板之前，先复用合法本地参考，确实无参考图时再拆为「内部结构参考 → 固定风格重绘」
→ preflight 在工具调用前校验哈希、模式、输入权利、绑定和冲突词，并输出不经手改的 `tool_request`
→ 适用于 APPSO 编辑创意图；官方证据图、真实界面、Logo 与精确数据图默认不套该风格
```
