# 事实卡

## 时间与身份

- OpenAI 发布页日期：2026-07-15。
- 官方 X 宣布时间：2026-07-15 17:34:29 UTC，即北京时间 2026-07-16 01:34:29。
- GPT‑Red：OpenAI 内部自动化安全红队模型；不向用户部署，与生产模型分开保存。
- 预印本：截至北京时间 2026-07-16 12:13 尚未发布；官方称本周晚些时候发布。

## 方法

- 训练方式：self-play reinforcement learning。
- 攻击方：生成并迭代攻击，成功诱发符合场景定义的失败时得到奖励。
- 防守方：抵抗攻击并完成用户原始任务时得到奖励；单纯拒绝所有内容不算理想防守。
- 场景：攻击者可控制本地文件、网页横幅、邮件正文或工具输出的一部分；每个环境都有明确威胁模型与成功条件。
- 用途：GPT‑Red 生成攻击样本，供 GPT‑5.6 的对抗训练使用。
- OpenAI 称 GPT‑Red 训练使用的计算规模可比其部分最大后训练任务；前身模型从 GPT‑5.3 起已用于后续生产模型训练。

## 主要结果

- 内部复刻的间接提示词注入 Arena：目标 GPT‑5.1；新场景与训练场景不同；GPT‑Red 场景成功率 84%，人类红队 13%。
- 最难的直接提示词注入 benchmark：GPT‑5.6 Sol 失败量约为四个月前最佳生产模型的六分之一。
- 早期 GPT‑Red 找到 Fake Chain-of-Thought 直接注入：GPT‑5.1 上攻击成功率最高超过 95%，GPT‑5.6 Sol 上低于 10%。
- GPT‑5.6 Sol 在保留环境中只对 GPT‑Red 的 0.05% 直接注入失败；这是内部口径，不等于现实世界绝对安全率。
- 若干面向开发工具和浏览的间接注入 benchmark 已超过 97% 准确率。

## 真实系统案例

### 售货机 Agent

- 系统：OpenAI 办公室实际运行、由 Andon Labs 制作的 Vendy 类售货机 Agent。
- 流程：GPT‑Red 获得系统描述，可发送攻击并观察与真实部署接近的模拟 Agent 工具调用；迭代后把攻击转到生产 Agent。
- 结果：高价现货改到最低 0.5 美元；订购 100 美元以上新品并以 0.5 美元出售；取消另一位顾客的订单。
- 边界：OpenAI 安排的受控红队测试；页面没有披露实际经济损失，也没有公开攻击 payload。

### Codex CLI Agent

- 目标：基于 GPT‑5.4 mini 的 Codex CLI Agent。
- 设置：10 个保留的数据外泄场景；与 prompted GPT‑5.5 baseline 比较。
- 结论：OpenAI 称 GPT‑Red 在更多场景成功且 token 更省；发布页没有给出完整数字。

## 解释边界

- 84% 是“多少场景至少找到一次有效攻击”，不是单次攻击成功率，也不是公平匹配预算后的职业能力排名。
- “6x fewer failures”是内部 benchmark 相对结果，正文写成“失败量约为对照的六分之一”，不写“现实攻击下降六倍”。
- 售货机与 >97% benchmark 不是同一目标、模型和场景，只能用来解释静态评测的覆盖边界，不能做数值对照。
- 自动化红队、搜索式攻击和 RL 攻击模型已有公开研究。GPT‑Red 当前可见的新意主要在规模、攻防共同训练和进入生产后训练流程；完整学术贡献要等预印本。
