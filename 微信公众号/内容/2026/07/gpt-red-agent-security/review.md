## 人话自审与冷读

1. 开头只讲一件事：售货机 Agent 真的动用了改价、采购和取消订单权限。
2. 前四分之一已经出现核心做法：防守变强、攻击继续升级、成功攻击回流下一代模型训练。
3. 84% 对 13% 后立刻解释场景覆盖、预算缺失和不可直接给人类判输，数字没有悬空。
4. “>97%”与售货机案例先排除直接横比，再落到静态题库无法覆盖新攻击路径。
5. 结尾给出自适应攻击、完整系统、权限关口三项检查，并回到 0.5 美元案例。
6. 核心判断可复述：Agent 安全不是裸模型分数，而是一个会变化的攻击者能否借外部文字动用真实权限。
