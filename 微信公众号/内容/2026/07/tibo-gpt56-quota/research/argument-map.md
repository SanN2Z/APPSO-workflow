# 二轮论证图（主编锁定版）

## 一句话因果链

```text
峰值能力决定理论上限
        ↓
可获得性 × 工作连续性 × 成本可预测性 × 入口占有
        ↓
能力能否稳定变成用户的日常产出与长期留存
```

这里的乘号只表示四项都可能成为短板，不表示一个可计算的学术公式。正文必须逐项用文字定义和举证。

## 证据映射

| 模块 | 人话问题 | 本文证据 | 主要限制 / 反例 | 读者后果 |
|---|---|---|---|---|
| 开场冲突 | 为什么一次 reset 会引来同行阴阳 | ClaudeDevs 公告、Tibo 回复 | 截图证明互动，不证明 Anthropic 动机 | 额度已成为竞争现场 |
| 事实卡 | 这次到底发布和改变了什么 | 三档、价格、max/ultra、Work、reset 定义 | 只建背景，不判胜负 | 不看发布会也能进入分析 |
| 峰值能力 | 模型在理想条件下会不会做 | 厂商六项评测、独立榜单 | 配置不统一；独立结果未齐；题集有缺陷 | 跑分只能回答部分问题 |
| 可获得性 | 谁现在能拿到 | 模型上线范围、订阅访问 | reset 不等于永久扩容 | 能力必须先触达用户 |
| 工作连续性 | 活能否从开始做到交付 | Claude reset、5 小时和每周额度规则 | 时间接近不等于因果；可能有促销/服务替代解释 | 中断会逼用户临时换工具 |
| 成本可预测性 | 团队敢不敢长期用 | Luna/Terra/Sol 价格梯度、max/ultra 预算方式 | token 单价不等于任务总成本 | 影响预算、采购和规模化 |
| 入口占有 | 用户会不会每天打开 | ChatGPT Work 与 Codex 统一入口 | 用户数与用途为厂商自报 | 文件、权限和习惯形成黏性 |
| 额度的准确位置 | 为什么它值得做标题钩子 | 用户最先感到的任务中断与续杯 | 它主要证明连续性，不代表四项全部 | 把热点变成工作判断 |
| 结尾 | 谁更可能长期留下 | 四项证据回收 | 不做“一次 reset 决胜”的外推 | 稳定产出比一时峰值更能留住用户 |

## 写作顺序

```text
Tibo / Claude 冲突
→ 60 秒事实卡
→ 前 25% 提出“峰值能力 + 四个产品化条件”
→ 峰值能力：跑分能说明什么、不能说明什么
→ 可获得性与工作连续性：reset 补了什么、没补什么
→ 成本可预测性：单价为什么不是最终账单
→ 入口占有：Codex 搬进 Work 为什么重要
→ 回到额度与 Tibo，落在长期日常产出
```

## 不允许混用

- 峰值能力不是四个产品化条件之一。
- 额度主要归入工作连续性，只能说明部分可获得性。
- 入口占有必须在文字和图中同时出现。
- 用户迁移是合理机制判断，不写成已测得的普遍行为比例。
