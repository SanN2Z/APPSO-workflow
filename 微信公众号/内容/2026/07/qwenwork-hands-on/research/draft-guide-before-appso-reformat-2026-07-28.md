# 千问办公功能全指南：桌面、IM、Office 和 Skill 怎么配合

打开千问办公官网，最显眼的是六项能力：企业协作、Office 产物、多模态、网页、数据源和技能市场。再点进帮助中心，菜单会继续展开：电脑操控、应用快照、IM 频道、定时任务、Hooks、连接器、三个工作台……

功能很多，也很容易看乱。

理解千问办公，最好不要背菜单。它想做的是一条完整链路：

> 把材料交给 AI → 让它调用电脑和外部服务 → 生成可编辑的文件或网页 → 把结果送回原来的聊天 → 将有效流程保存下来、定时重复。

这篇就按这条链路，把千问办公目前写进官方页面的功能捋一遍。

## 从哪里使用：桌面是目前最完整的入口

千问办公已经提供 macOS 14+ 和 Windows 10+ 64 位桌面客户端。桌面端是它的控制中心，本地文件、电脑操控、应用快照、IM、Skill、连接器和定时任务都在这里汇合。

官网所说的「本地运行」，指客户端在电脑上运行，并能在授权后接触本地文件和应用；不能据此推断大模型全部在本机离线计算。

官方帮助文档还描述了网页端和钉钉内入口。不过，官网部分位置仍把网页版和企业注册标为「敬请期待」。这说明产品还在分阶段开放，同一项能力是否可见，要以账号、套餐和组织权限为准。

## 先把材料放进一个「任务」

千问办公的基本单位不是一问一答，而是「任务对话」。一个任务里可以放多轮沟通、附件、执行过程和最终产物。同一份报告的补充材料、改结构和换格式，可以继续留在原任务里。

材料可以来自本地文件或「我的网盘」。官方文档列出的常见格式包括 PDF、Word、Excel、PPT、CSV 和 TXT；图片、音频、视频和语音也可以成为输入。桌面端的「应用快照」还能抓取当前窗口的截图与可读文字，用作本轮任务的上下文。

复杂任务可以选择旗舰模型，格式转换、润色等规则明确的工作可以使用标准模型。同一任务中切换模型，已有上下文会保留。

## 不只生成内容，还能动电脑

千问办公桌面端可以调用「电脑操控」，直接操作电脑上的应用。官方给出的场景包括文件整理、桌面应用操作和浏览器自动化。用户需要写清应用、路径、目标，以及是否允许提交或删除；涉及高风险操作时，官方建议采用「每次询问」。

它的扩展中心又分成三类：

- **连接器**：接入网页、日历、邮件、企业协作平台或其他数据源，通常需要登录、填写参数或授权；
- **技能 Skill**：保存某类任务的固定流程，例如周报、文档整理或信息图制作；
- **专家套件 Expert Kit**：把某个岗位需要的技能、连接器和工作方法组合在一起。

三者不是安装后永远自动生效。官方文档提醒，使用时可以手动添加资源，或在指令里明确要求调用。更新专家套件还可能覆盖个人修改，更新前最好先保存。

面向更熟悉自动化的用户，桌面端还有 Hooks。它允许在执行节点插入自定义逻辑，例如在工具运行前拦截危险操作，或在写入文件后自动做检查。

## 最终能交付什么

Office 是千问办公最直观的一层。官网列出的输出格式包括 PPTX、Word、Excel 和 HTML，生成后可以继续预览和编辑。产物会进入 Agent 工作区，也可以在「我的网盘」里查找、重命名、下载或继续使用。

除了通用任务页，千问办公还有三个垂直工作台：

- **写作工作台**：面向文章、报告和内部文档，产物以 Markdown 保存在本地 `outputs/` 目录，并保留迭代版本；
- **幻灯片工作台**：用专门的画布生成和调整演示文稿；
- **设计工作台**：以「设计即代码」的方式生成可运行、可编辑的视觉产物。

如果结果不只是文件，还可以交给 QwenWork Pages。它能生成静态页面，也能制作带表单、数据库和交互逻辑的动态页面；发布前先预览，发布后获得 `qwenwork.host` 域名。每次重新发布都会产生新版本，可以切回旧版。

## 任务也可以从群聊里来

千问办公目前在官方文档中列出了 7 类 IM 入口：钉钉、飞书、Lark、微信、企业微信、Slack 和 WhatsApp。

它的原则是「哪里来的，回哪里去」：在某个聊天窗口下达任务，结果就回到同一窗口；不同平台、不同群聊对应独立会话，避免上下文混在一起。钉钉、飞书等频道还能选择开放或配对模式。

如果任务已经在电脑上进行，手机可以发送 `/bind`，把当前聊天绑定到某个桌面任务；之后在手机补材料、看进度，结果仍会同步回来。`/unbind` 则解除绑定。

## 让它到点自己工作

定时任务适合日报、周报、竞品监测和文件整理。用户可以直接用自然语言说明频率、工作目录、数据来源和输出位置，也可以在界面里选择一次、间隔、每小时、每天、每周或每月。

桌面端的定时任务由本地客户端调度。电脑睡眠或关机时不会触发，错过后也不会自动补跑；每次运行会新建独立对话并消耗 Credits。官方建议先手动跑通，再改成定时任务。

网页端文档描述的是云端定时任务，退出浏览器后仍可继续。两种入口的执行条件不同，使用前要看清任务建在哪里。

## 使用前，记住三件事

第一，桌面客户端能碰本地文件，不等于数据天然不会离开电脑。模型调用、云盘、连接器和网页发布涉及不同的数据路径，敏感资料要先看企业策略和授权范围。

第二，「我的网盘」没有回收站，也不自动备份。删除文件夹会永久删除其中内容。网页删除同样不可恢复；如果动态网页连接数据库，删除网页还会清空关联数据。

第三，官方文档、官网入口和当前账号可能不同步。看到某项能力写进帮助中心，不代表所有用户已经同时获得。最稳妥的顺序是：先用虚构材料跑通一个小任务，再连接真实账号、开放目录或建立自动任务。

把这些模块连起来，千问办公就不只是一个会写文档的聊天框。它更像一张工作台：上面放着本地文件、Office、群聊、网页、Skill 和自动任务。

至于它能替你走多远，先看你的账号开放了哪些入口，再看你愿意把哪些权限交给它。
