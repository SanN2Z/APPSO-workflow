# 选题简报

- 类型：即时资讯 / 吃瓜短评
- 核心事件：北京时间 2026 年 7 月 16 日 11:58，ClaudeDevs 宣布重置所有用户的 5 小时与每周用量限制；12:14，OpenAI 团队成员 Tibo 宣布再次重置 Codex 与 ChatGPT Work 用户的每周额度，并称两项产品合计活跃用户达到 900 万。
- 核心钩子：两条帖文只隔 16 分钟，像一场用额度打起来的朴素商战。
- 作者判断：Token 不只是成本，也会改变人的行动。额度一满，待办事项就开始催人开工。
- 读者收获：看懂两家到底重置了什么，同时不把 reset 误写成永久免费或无限使用。
- 篇幅：约 1200 字，轻、快、有梗，不展开做模型能力评测。

## 事实边界

- 16 分钟的先后关系是真实时间差，不足以证明 OpenAI 因 Anthropic 的帖文临时采取行动。
- reset 是当期用量计数恢复，不等于永久提额、无限使用或 API 限流取消。
- Tibo 的 900 万是 Codex 与 ChatGPT Work 合计活跃用户的团队自报，未给统计窗口；不能写成 Codex 周活 900 万。
- Anthropic 没在这条帖文里说明本次 reset 的原因，不补写故障、补偿或狙击竞品剧情。
