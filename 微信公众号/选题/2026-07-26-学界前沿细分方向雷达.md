# 学界前沿细分方向雷达：多模态、世界模型与 AI4S

## 先说结论

这轮最强的共同信号，不是「三个领域都在继续堆大模型」，而是创新重心正在往四个接口下沉：

1. **表示接口**：不同模态能否使用同一套 token、状态或科学语法，而不是在模型外拼接多个专家。
2. **记忆接口**：模型能否在长视频、长任务和长实验里保留事件、对象、因果与不确定性，而不是只扩大上下文窗口。
3. **行动接口**：世界模型能否准确响应动作、支持反事实规划，并在不同机器人本体或不同科学工具之间迁移。
4. **验证接口**：AI4S 不再只看静态预测分数，而是要求域外泛化、扰动响应、极端事件、实验闭环和可执行证据。

对小团队、研究生或内容选题来说，最值得抢的通常不是从头训练一个 10B 级通用模型，而是为这些接口建立新表示、新记忆、新校准方法、新 benchmark，或者把它们放进一个此前没人认真验证的真实科学场景。

## 三个领域各自发生了什么

### 多模态：从「会看会听」转向「会选择、会记、会交错行动」

- **统一 token 正成为主战场。** UniAR 使用同一离散视觉 tokenizer 服务理解和生成，让模型可以直接解释自己刚生成的视觉 token；并用 bitwise 量化与并行预测缩短视觉序列。AR-Omni、NExT-OMNI、UniCM 等路线则分别押注纯自回归、离散流匹配和 consistency model。说明目前没有单一路线胜出，tokenizer、训练平衡和推理效率仍有大量可做空间。
- **多模态记忆不再等同于文本摘要。** AOP-Agent 用层级音视频记忆和 observe-reflect-replan 循环，在不额外训练的情况下做主动感知；PyraVid 则按事件构建粗到细的记忆金字塔，并能找回语义相似度不高、但因果关联强的片段。
- **图像开始成为推理动作，而不只是输入或最终结果。** BRAID 将 text-image-text 轨迹建模为统一 MDP，并给中间图像分配推理效用奖励。这里真正开放的问题，是中间视觉步骤究竟带来信息，还是只让视觉 Judge 更容易给高分。

### 世界模型：从「生成一段未来」转向「能不能用于行动」

- **跨本体动作表示在升温。** OSCAR 用 2D 运动骨架作为统一动作条件，覆盖不同机械臂甚至人手；另一条路线则从野外视频学习 latent action，试图绕过大规模动作标注。
- **学界开始把世界模型当作 policy evaluator。** OSCAR 和 Interactive World Simulator 都报告了虚拟评测与真实评测之间的相关性；后者还报告单张 RTX 4090 上以 15 FPS 稳定交互超过 10 分钟，并称用模型生成数据训练的策略可与等量真实数据训练的策略相当。它们仍是作者自报的预印本结果，下一步关键不是生成质量，而是 ranking calibration、失败覆盖和域外可靠性。
- **「看着像物理」与「学会物理」正在被拆开。** ACWM-Phys 中，模型在视觉简单、低维、几何清晰的互动上泛化较好，但在软体接触、高维控制和复杂关节运动上明显下滑。作者据此判断，当前模型仍较依赖外观模式。
- **规划会攻击模型。** 推理时优化会主动寻找世界模型的幻觉，从而得到在模型中高分、真实世界失败的动作序列。世界模型的 UQ、拒绝机制、保守规划和 anti-hacking benchmark 很可能形成一个独立分支。

### AI4S：从「预测得准」转向「能否干预、实验和解释」

- **科学基础模型正在分成两条路线。** 一条是 LOGOS 这样的通用科学语法，想把多领域对象统一成 next-token prediction；另一条是 LSM、SEM 这样的仪器原生模型，用大量未标注科学图像预训练，再做少样本适配。后一条对小团队更现实。
- **基础模型的「通用性」正在被重测。** 单细胞与空间转录组统一评测发现，没有模型在所有任务上占优；细胞级 Transformer、空间图模型和语言衍生 gene embedding 各自在不同任务上更强。能否跨模态、跨实验室、跨扰动稳定泛化，比模型规模更值得写。
- **极端事件暴露平均分掩盖的问题。** Aurora 在 1—7 天的多类极端天气上表现较强，但在 14—21 天预测中，尽管大尺度环流仍有技巧，阈值型极端强度会向气候平均坍缩。AI 天气的下一步不是只比 RMSE，而是概率校准、尾部事件和实际影响。
- **科学 Agent 的瓶颈已被量化。** SciAgentArena 的约 200 项任务显示，当前 Agent 对明确的数据分析流程更有效，却难以持续自主探索和提出稳健的新见解；EXP-Bench 的 461 个任务中，完整可执行实验成功率只有 0.5%。这给「实验可执行性、失败恢复、数据血缘、结果审计」留下了很大的创新空间。
- **闭环发现开始有可组合 benchmark。** MADE 把材料发现建模为受 oracle 预算约束的顺序决策过程，可替换生成器、过滤器、规划器和工具，对完整发现流水线做消融。这类环境可能比静态材料属性榜单更接近下一阶段主战场。

("foundation model" OR "scientific agent" OR "closed-loop discovery")
AND (microscopy OR spectroscopy OR "spatial transcriptomics"

## 目前最值得写成选题的 6 个角度

1. **《世界模型最危险的 bug，不是画糊，而是会骗规划器》**  
   用 ACWM-Phys、虚拟 policy evaluation 与 inference-time planning 的 model hacking 串起「好看、懂物理、能行动」三种不同能力。

2. **《多模态真正的下一战：不是看得更多，而是知道下一步该看哪里》**  
   用 MOV-Bench、AOP-Agent 和 PyraVid 讲主动感知与层级记忆，避开单纯比上下文窗口。

3. **《AI 科学家会写实验，为什么完整跑通只有 0.5%》**  
   用 EXP-Bench、SciAgentArena 和 MADE，把「科学推理」拆成假设、实现、执行、分析、验证和可复现交付。

4. **《显微镜，可能是科学基础模型最先跑通的入口》**  
   对比自然图像 VLM 与 LSM / SEM 仪器原生模型，核心不是模型更大，而是未标注体数据、少样本专家标签和设备闭环能形成飞轮。

5. **《AI 天气模型记得台风怎么走，却会忘记它有多极端》**  
   用 Aurora 的 1—7 天与 14—21 天差异，解释平均误差、环流结构和尾部强度为什么不是同一件事。

6. **《一个模型做所有科学，真正难的不是参数，而是科学怎么变成 token》**  
   以 LOGOS 为正面案例，再用单细胞统一评测提醒读者：统一表示不等于跨任务、跨模态和跨实验室都能泛化。

## 优先级建议

如果下一步只继续追 3 条，我建议：

1. **世界模型的 anti-hacking + 虚拟评测校准**：学术缺口明确，也和现有 FLUX 3 / Physical AI 选题形成互补，不再重复「视频模型能控制机器人」。
2. **仪器原生科学基础模型**：最容易落到真实场景、少样本与公开代码，且大众内容里还远未写烂。
3. **主动多模态感知与层级记忆**：计算门槛相对低，能从「上下文越长越好」切出一个反直觉判断。

## 不建议优先追的伪创新

- 只换一个视觉编码器或 LLM，在同一静态 benchmark 上涨 1—2 分，却没有域外、长时、干预或成本分析。
- 把视频生成的主观质量直接当成世界模型的物理正确性或 policy usefulness。
- 做一个通用 RAG + 多 Agent 壳子，就宣称能自主科学发现，却没有可执行实验、失败记录和结果复核。
- 在材料、分子或单细胞任务中继续使用随机划分，把近重复样本泄漏包装成零样本泛化。
- 只看天气场平均 RMSE，不报告极端事件、概率校准、区域偏差和实际影响指标。

## 证据边界

- 本轮核心论文大多是 2026 年 arXiv 预印本；所有性能数字首先是作者报告，不代表已经独立复现。
- ICLR Workshop 与 OpenReview 投稿页是方向发现入口，不能自动写成主会录用或学界共识。
- 「容易创新」是根据公开 failure mode、数据可得性、评测空缺和计算门槛做出的研究机会判断，不是成功概率保证。
- 多模态、世界模型和 AI4S 正在相互融合，但不能因此把任何视频生成器都称作物理世界模型，也不能把任何科学问答 Agent 都称作自主科学家。
