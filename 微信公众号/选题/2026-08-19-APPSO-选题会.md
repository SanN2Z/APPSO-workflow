## 原候选 1

### Cursor 不只替你写代码，还想把代码仓库一起接走

- 稿型 / 栏目：产品／行业解释稿；AI 编程工具与开发者基础设施。
- 5 秒事实：Cursor 在 8 月 17 日发布 Origin 代码托管早期测试，提供仓库、PR、代码浏览和 GitHub 同步，并把 Agent、代码和 PR 放在同一工作区；功能正向付费方案逐步开放，企业管理员可选择退出。
- 今天新增：Cursor 此前主要争夺编辑器与编程 Agent 入口；Origin 第一次把它推进到代码长期存放、协作和审计层。同日 GitHub 出现大范围故障，只能作为开发者依赖单一平台的背景，不能推断 Cursor 刻意借故障发布。
- 读者问题：当 AI 编程工具既能改代码、又托管仓库和 PR 时，开发团队到底是获得了更短的工作流，还是把代码、权限与审计一起交给了新的平台？
- AI 的具体任务：先用公开文档制作 Cursor Origin、GitHub 和 GitLab 的功能／迁移矩阵，逐项核对事实源、权限、PR 评论同步、CI 接入、导出与删除路径。只有锁题后获得明确授权和合格付费账号，才用一次性私有仓库测试 GitHub 双向同步、断开连接与 CI；没有授权时不创建仓库、不冒充实测。
- 核心冲突或价值：对编程 Agent 来说，代码托管不是一个被动硬盘，而是上下文、身份权限、分支、PR、CI 和审计日志汇合的控制层。Cursor 把这些环节并到 Agent 旁边，可能降低往返成本，也可能把编辑器锁定升级为工作流和数据锁定。最强的替代解释是：Origin 现阶段只是方便的 GitHub 镜像，且 GitHub 来源仓库仍由 GitHub 充当事实源；早期测试并不足以证明开发者会迁移。
- 一手来源：[Cursor：Origin 代码托管公告](https://cursor.com/changelog/origin-code-hosting)、[Warp：Factories 产品页](https://www.warp.dev/factories/request-access)。Warp 只作为「Agent 工具向软件交付控制层扩张」的旁证，其自动化比例、成本和运行量均属厂商自报。
- 独立核验：[TechCrunch 对 Origin 的报道](https://techcrunch.com/2026/08/18/cursor-capitalizes-on-github-frustration-launches-rival-hosting-platform/)。报道把它称为 GitHub 竞品属于媒体判断，不等于 Origin 已具备 GitHub 的完整生态与治理能力。
- 配图来源：Cursor 官方更新页的 Origin 界面图、基于公开功能制作的原创「编辑器—Agent—仓库—PR—CI」关系图；若后续获授权实测，再使用自有仓库截图并遮蔽仓库名、组织名和账号信息。
- 权利初判：`pending`。官方产品图仅作新闻报道引用，发布前核对媒体使用条款并保留出处；原创关系图归项目所有；不得用 GitHub 故障截图暗示 Cursor 与故障存在因果关系。
- 事实边界：Origin 是早期测试，不是完整替代 GitHub 的已完成产品；GitHub 来源仓库支持同步，GitHub 仍可作为事实源；公告中的部分 Agent-native 功能仍是「即将推出」；不能把同日故障写成 Cursor 的发布动机；不能把 Warp 的自报指标当独立结果。
- 与近期已发内容的差异：仓库现有稿件主要涉及模型、Harness 和 Agent 评测；本题只写 AI 编程厂商从编辑器／Agent 入口向代码托管与交付控制层扩张，不重复「哪个模型更会写代码」。
- 预计时效窗口：24—48 小时；若 Cursor 公布定价、数据迁移／删除条款、企业控制和首批 Agent-native 功能，立即补充。

## 原候选 2

### ChatGPT 开始自动判断你是不是未成年人

- 稿型 / 栏目：消费产品／安全解释稿；AI 教育与青少年产品设计。
- 5 秒事实：OpenAI 在 8 月 18 日推出 ChatGPT for Teens；用户自报 13—17 岁，或被系统估计为未满 18 岁，会自动进入青少年体验，获得更严格的内容与关系边界保护，并加入学习导向功能。
- 今天新增：家长控制、未成年人规范和年龄预测此前已分别存在；这次新增的是把它们组合成默认的年龄分流产品。产品不再只问「家长开了什么设置」，而是先由年龄声明或预测决定用户进入哪套模型行为。
- 读者问题：谁来判断一个用户是不是未成年人？哪些保护无需家长介入就会生效，哪些数据和功能开关仍需家长与青少年关联账号后才能管理？
- AI 的具体任务：只基于公开公告、帮助页和 Model Spec 制作「自动生效／账号关联后可控／默认开启／默认关闭」四栏矩阵，再用公开示例对比学习引导、敏感内容、情感依赖和家长通知的产品边界。不创建虚假未成年人账号，不收集或测试真实未成年人的聊天数据。
- 核心冲突或价值：OpenAI 试图把年龄从注册信息变成模型路由信号，让安全保护在没有家长介入时也能默认生效；但官方帮助页同时显示，「用于改进模型」默认开启，记忆在可用地区通常默认开启，语音、图像生成以及部分网络能力也各自默认开启。家长关联后可以管理部分设置，却不能阅读聊天记录或实时监控。最强的替代解释是：这只是既有家长控制和安全规范的重新包装；要证明产品层真的改变，正文必须抓住自动分流、默认行为和设置矩阵，而不能只复述宣传语。
- 一手来源：[OpenAI：ChatGPT for Teens 公告](https://openai.com/index/chatgpt-for-teens/)、[OpenAI：家长控制帮助页](https://help.openai.com/en/articles/12315553-parental-controls-faq)、[OpenAI：年龄预测方法说明](https://openai.com/index/our-approach-to-age-prediction/)、[OpenAI：未成年人使用年龄要求](https://help.openai.com/en/articles/8313401)。
- 独立核验：[AP 对产品和外部质疑的报道](https://apnews.com/article/650cb35591de6546054d6c4e73b3290a)。Fairplay 对长期记忆并非默认关闭的批评属于第三方判断，应与官方功能事实分开。
- 配图来源：OpenAI 官方公告和帮助页的产品示意、自制「年龄判断—体验分流—默认保护—家长可控项」流程图；不使用真实未成年人的头像、对话或身份信息作装饰。
- 权利初判：`pending`。官方产品图仅作新闻报道引用，保留完整来源；原创流程图归项目所有；如需人物场景图，优先使用权利明确的抽象插画并避免制造真实个案感。
- 事实边界：默认保护的有效性目前主要是 OpenAI 自报，不能写成已经解决自伤、饮食障碍或情感依赖风险；没有公开证据足以评价年龄预测准确率；13 岁以下仍不属于 ChatGPT 面向的用户，13—18 岁使用需符合当地要求和家长同意；家长控制不会提供聊天记录或实时监控；「用于改进模型」与记忆的默认状态可能因地区而异。
- 与近期已发内容的差异：8 月 18 日选题会的 ChatGPT 题目关注广告和对话定向；本题只写年龄分流、默认安全行为与家长／青少年之间的控制边界，不重讲 OpenAI 商业化。
- 预计时效窗口：24 小时；若 OpenAI 发布年龄预测评估、地区覆盖、青少年专属系统卡或实际界面，优先更新。

### 加扫 1：Perplexity 白送一年会员，第一次走到「续费还是离开」

- 稿型 / 栏目：AI 商业／订阅增长解释稿。
- 5 秒事实：Perplexity 与 Airtel 曾向 3.6 亿名印度客户提供一年 Pro 会员。TechCrunch 在最早一批会员开始到期后汇总 Sensor Tower 与 Appfigures 数据：活动开放领取的 7 个月内，印度下载量约 5600 万；月活从活动前约 260 万的平均水平升至峰值约 2200 万，2026 年 7 月仍接近 1400 万。停止新增领取后下载量大跌，但移动端收入估计继续增长。

## 高价值追更：不建议新开

### 一个模型还没发布，OpenAI 先让最大一轮强化学习继续停着

- 新事实：OpenAI 在 8 月 18 日称，Hugging Face 事件与对 Astra 的初步评估促使其暂停面向部署的最新模型强化学习；两周后，最大一轮计划中的前沿强化学习仍处于暂停状态。对带工具的 Astra 推理，OpenAI 引入持续监控，目标是在 30 分钟内触发处置，并估算监控消耗约相当于被监控推理算力的 20%。
- 可新增判断：安全第一次以明确的训练节奏、推理延迟和算力开销进入产品成本表；「模型能力是否越过阈值」不再只是发布前的一份评测报告，而会直接决定训练和推理能否继续。
- 为什么不新开：仓库 8 月 10 日选题雷达已有 Agent 逃离评测沙箱方向，现有 Astra 稿件也在处理中。优先把这组官方数字回填既有安全追踪，避免同时开第三个 Astra／Agent 安全题。
- 一手来源：[OpenAI：在网络安全关键能力时代调整模型开发节奏](https://openai.com/index/pacing-model-development-cyber-capabilities/)。
- 事实边界：Astra 是否达到「Critical cybersecurity capability」仍是初步证据，不是定案；并非 OpenAI 所有训练都停止；20% 是 OpenAI 对当前监控开销的估算；技术报告尚未发布，事件经过和监控效果仍属厂商自报。
