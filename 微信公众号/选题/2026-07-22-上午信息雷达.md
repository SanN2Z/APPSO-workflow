## 主推 1

### Substack 开始查 AI 稿，最后把判断权还给了读者

- 稿型 / 栏目：时效热点 × AIGC 解释稿；平台机制与创作者信任。
- 5 秒事实：Substack 与 Pangram 合作，为 7 月 21 日起发布、超过 100 个词的帖子、Notes、回复和评论提供 AI 文本扫描；结果只向主动请求扫描的人显示。
- 今天新增：这不是后台自动给作者贴标签。读者决定是否扫描，作者可以在发布前自检、补充「How I make this」创作过程说明，也可以报告并移除自己认为错误的扫描结果。功能已上线网页和 iOS，Android 后续提供。
- 读者问题：当一篇文章同时包含作者经验、AI 整理和人工改写时，一个检测分数究竟能证明什么？平台该替读者判刑，还是只提供来源线索？
- AI 的具体任务：根据文本的结构、风格与语义模式，估计其中更像人工写作或 AI 辅助的比例。Pangram 的独立产品还能标出疑似片段。它做的是来源概率判断，不是评估观点、事实、用心程度或作者责任。
- 核心冲突或价值：Substack 一边引入检测器，一边明确承认「检测到 AI」不等于「没有人认真创作」。产品真正有意思的地方，是把检测、解释、申诉与读者选择放在同一套机制里。
- 一手来源：[Substack 创始人 Chris Best 的产品说明](https://post.substack.com/p/against-claudefishing)、[Pangram 产品页](https://www.pangram.com/)。
- 独立核验：[Chicago Booth Review 对英文材料研究的摘要](https://www.chicagobooth.edu/review/do-ai-detectors-work-well-enough-trust)显示，研究者以约 2,000 段人工写作文本为基础，再用 4 个模型生成对照版本。Pangram 等商业检测器在中长文本上表现较好，但结果会随文本长度、模型与判定阈值变化；短于 50 个英文单词的材料更难判断。
- 配图来源：优先使用编辑部自行操作后的界面截图；补一张原创流程图，画清「读者发起扫描 → 系统给估计 → 作者解释或申诉」。如引用 Substack 官方界面图，仅作评论报道并标明来源。
- 权利初判：自制流程图权利清晰；自有实测截图可用；官方界面图按有出处的评论素材处理，不暗示获得商业授权。锁题后逐张登记 `asset-manifest.yml`。
- 事实边界：Substack 官方说的是「估计」，不是鉴定。独立研究主要测试英文、人工文本与模型生成文本，不能外推到中文、翻译文本或复杂的人机混写。Pangram 自称 99.98% 准确和支持 20 多种语言，均不能直接当成中文场景的独立结论。
- 与近期已发内容的差异：近期内容集中在 Agent 的执行风险、模型价格和产品能力；这篇讨论的是内容平台如何分配「检测权、解释权和误判责任」。虽然知识库已有其他平台「反 AI」旧案，但本次产品机制是读者按需扫描与作者过程披露，不是自动封禁或惩罚。
- 预计时效窗口：24 小时内锁题；若能访问功能，当天完成一次人写、纯 AI、人工改写三组对照。没有实测时仍可写机制解释，但标题不得暗示我们已经验证其准确率。

#### 建议结构

1. 从读者点一下就能查看 AI 辅助估计的产品动作开场。
2. 拆清它没有做什么：不自动公开贴标、不直接惩罚作者，也不判断文章有没有价值。
3. 用独立研究解释检测器在哪些条件下有效，以及长度、阈值、语言和新模型为什么会改变结果。
4. 落到创作者的现实选择：与其假装完全没用 AI，不如说明 AI 做了哪一步、事实和观点由谁负责。

#### 给领导的选题话术

> Substack 7 月 21 日上线了一项很容易吵起来的新功能：读者可以主动扫描文章、评论和回复，查看其中多少文字可能由人写、多少经过 AI 辅助。但平台没有自动贴标签或处罚作者，反而允许作者公开「我是怎么做出这篇内容的」，并申诉误判。文章不做「检测器抓 AI」的旧故事，而是讲清平台如何把检测权交给读者、把解释权留给作者，以及一个分数为什么永远测不出观点和责任来自谁。

## 主推 2

### 第三方综合分没涨，任务时间却砍半：Google 开始卷 Agent 的工时和账单

- 稿型 / 栏目：跑分之外；模型经济性解释稿。
- 5 秒事实：Google 7 月 21 日发布 Gemini 3.6 Flash、3.5 Flash-Lite 和限量开放的 3.5 Flash Cyber。3.6 Flash 官方定价为每百万 Token 输入 1.50 美元、输出 7.50 美元，已经进入 Gemini API、AI Studio、Gemini 产品与 GitHub Copilot 的渐进推送。
- 今天新增：第三方 Artificial Analysis 的同一套任务评估中，3.6 Flash 的 Intelligence Index 与 3.5 Flash 同为 50，但中位任务时间从 2.7 分钟降到 1.3 分钟，单项任务成本从 0.59 美元降到 0.50 美元。真正的新变量不是「更聪明」，而是相近能力完成一项工作要多久、烧多少钱。
- 读者问题：开发者看到输入、输出 Token 单价以后，怎样判断一个模型到底便宜不便宜？普通用户为什么也该关心模型一次任务会跑多少轮、吐多少字？
- AI 的具体任务：执行需要多轮推理和工具调用的 Agent 工作流。比较单位从「回答一个问题的 Token 价格」改成「完成一项任务的时间、输出量和总成本」。
- 核心冲突或价值：Flash-Lite 的名义单价更低、第三方综合能力分也明显上涨，但该评估中的单项任务成本反而从 0.04 美元升到 0.09 美元。便宜模型变聪明以后，可能因为做得更多、写得更多而让整项工作更贵。
- 一手来源：[Google 官方发布](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-6-flash-3-5-flash-lite-3-5-flash-cyber/)、[Gemini 3.6 Flash 模型文档](https://ai.google.dev/gemini-api/docs/models/gemini-3.6-flash)、[GitHub Copilot 接入公告](https://github.blog/changelog/2026-07-21-gemini-3-6-flash-is-now-available-in-github-copilot/)。
- 独立核验：[Artificial Analysis 的新旧模型同口径任务数据](https://artificialanalysis.ai/articles/gemini-3-6-flash-3-5-flash-lite-halving-time)可用于比较时间和单项成本；[Ars Technica 的发布报道](https://arstechnica.com/google/2026/07/google-reveals-faster-and-cheaper-gemini-3-6-flash-says-3-5-pro-is-still-in-testing/)可交叉核对产品时序，但没有完成独立性能复测。
- 配图来源：Google 官方模型家族图作有出处的报道素材；用公开数字重绘「能力分 / 任务时间 / 单项成本」三列对照图；如有 API 权限，再补同一任务的自有测试截图。
- 权利初判：原创数据图权利清晰，数据旁标注评测机构与口径；官方图片仅作评论报道并保留来源。锁题后登记 `asset-manifest.yml`。
- 事实边界：第三方结果只代表 Artificial Analysis 的任务集合，不等于所有 Agent 任务都快一倍。Google 的「少用 17% 输出 Token」、DeepSWE、OSWorld 与每秒 350 个输出 Token 等数字主要来自厂商测试，不能改写成「全面击败」。3.5 Flash Cyber 只向政府和可信合作伙伴限量开放，不得写成普通用户已经可用。
- 与近期已发内容的差异：知识库已有额度与 API 价格内容，这篇不再罗列价目表，而是把「Token 单价」推进到「每项工作总成本」。它也不复述当前 OpenAI 安全稿，而是回答模型如何成为更合算的生产工具。
- 预计时效窗口：12—24 小时内锁题。成稿前重开官方定价页，避免预览期价格或入口变化；能跑同一 Agent 任务时，优先补一次真实总 Token 与耗时对照。

#### 建议结构

1. 先放反常识结果：综合分没变，任务时间却从 2.7 分钟降到 1.3 分钟。
2. 解释为什么 Agent 的成本不能只看 Token 单价，还要看回合数、输出长度、工具等待和失败重试。
3. 用 Flash-Lite 的「单价低、单项任务反而更贵」做反例，提醒读者不要把价目表当总账单。
4. 收到产品判断：大模型竞争开始从最高分转向每项工作交付得多快、多稳、多便宜。

#### 给领导的选题话术

> Google 新发的 Gemini 3.6 Flash 在第三方综合能力分上没有超过上一代，完成同一套 Agent 任务的中位时间却从 2.7 分钟降到 1.3 分钟，单项成本也更低。更有意思的是，单价更便宜、能力提升明显的 Flash-Lite，单项任务成本反而翻倍。文章不做跑分搬运，而是借这组反常识数据讲清：Agent 时代真正该算的不是每百万 Token 多少钱，而是 AI 把一件活完整做完要花多少时间和总账单。
