# 2026-07-30 选题雷达

本轮按微信公众号 AI 与科技行业分析稿筛选，主要扫描 7 月 29 日至 7 月 30 日的新信号，并与 7 月已有选题、内容包和前两轮雷达去重。优先采用官方文件、官方技术说明和独立基准方材料；厂商自报与编辑判断分开处理。

## 先说结论

如果今天只新开一篇，主推 **FCC 把外国生产的先进机器人设备纳入 Covered List**。

这不是一条只属于人形机器人的政策新闻。正式定义按「能移动、能感知、能联网、由软件控制」划线，理论覆盖面可能延伸到机器狗、仓储机器人以及部分扫地机器人、割草机器人。真正值得写的判断是：Physical AI 的竞争刚从实验室走向市场，市场准入、生产地、固件更新和数据安全就开始成为与模型、硬件同等重要的门槛。

如果不想写政策，第二选择是 **同一模型只改两个 Harness 设置，ARC-AGI-3 公开集成绩从 13.3% 跳到 38.3%**。它能把抽象的跑分争议变成普通读者看得懂的具体问题：排行榜测到的究竟是模型，还是「模型 + API + 记忆 + 上下文管理」组成的系统。

偏工程与商业稿可选 **GPT-5.6 替自己的服务栈写 GPU Kernel，OpenAI 称端到端服务成本下降 20%**。这条的价值不在「AI 会写代码」的旧叙事，而在前沿模型能力开始直接转化为推理成本优势。

## 主推：美国给「外国机器人」划线，先撞上的可能不是人形机器人

### 新事实

7 月 28 日，美国 FCC 把「外国生产的先进机器人设备」加入 Covered List。正式文件明确：设备进入清单后，不能再获得新的 FCC 设备授权；外国生产商可以向美国战争部申请 Conditional Approval，获批设备可被豁免。

规则不是按某家公司点名，而是按生产地和功能定义。文件把先进机器人描述为能在地面移动、能远离操作员运行、总重量超过 4.4 磅，并同时具备环境传感器、至少 200 kbps 的网络连接和控制移动、感知、数据收集或远程操控的软件。软件范围还明确包含固件与 AI / 机器学习模型权重。

这一定义明确包含自主移动机器人、人形机器人和四足机器人。按功能推演，部分联网扫地机器人、割草机器人也可能落入范围，但是否受影响仍要看具体型号、生产地、是否已获得授权，以及后续解释或 Conditional Approval，不能把「可能覆盖」直接写成「所有产品已经禁售」。

### 核心判断

机器人安全正在从「厂商是谁」转向「机器能在现实空间里做什么」。一台会移动、会看、能联网、能通过软件更新改变行为的机器，不再只是家电或机械设备，也开始被视为可以持续收集空间数据、接受远程控制的计算终端。

对 Physical AI 公司来说，护城河也随之变化。模型能力、执行器和成本仍重要，但生产地证明、无线设备授权、固件与模型更新机制、数据流向以及申请例外的能力，会共同决定新品能否进入市场。

### 建议结构

1. 从「扫地机器人为什么会被机器人安全规则扫到」切入，不从宏观中美竞争起笔。
2. 拆解规则按功能划线的四个条件：移动、感知、联网、软件控制。
3. 解释 Covered List 的实际作用是卡住新的设备授权，不等于现有设备立即停用。
4. 再写产业影响：中国厂商在人形机器人、四足机器人和消费级移动机器人上更容易成为现实受影响者，但规则文本针对的是所有外国生产设备，并非只写中国。
5. 落到判断：Physical AI 进入现实世界后，能力、成本与市场准入将同时竞争。

### 可用标题

- 《美国给外国机器人划了一条线，扫地机器人也可能在里面》
- 《不是只有人形机器人：美国开始按「会移动、会看、能联网」管机器》
- 《外国机器人新型号撞上美国门槛，Physical AI 开始拼市场准入》

### 事实边界

- 规则写的是「所有外国生产」，不能简化成法律文本只针对中国；中国厂商是产业影响判断。
- 直接影响是新增设备授权，不是现有设备、既有获批型号立即被禁止使用或销售。
- 是否覆盖某款扫地机器人、割草机器人要按正式定义和授权记录逐款确认；标题只能写「可能」。
- Conditional Approval 提供例外路径，不能写成绝对、永久、无豁免的封锁。
- 设备获批后的软件与固件更新期限、硬件改款如何处理仍需查具体规则，首稿不写未经核实的截止日期。

## 第二选择：模型没换，两个设置让跑分从 13.3% 跳到 38.3%

### 新事实

OpenAI 7 月 29 日称，GPT-5.6 Sol 使用 ARC-AGI-3 官方 Harness 时，在公开任务集得到 13.3%；开启 retained reasoning 与 compaction 后得到 38.3%，输出 Token 同时减少到原来的约六分之一。OpenAI 估算同一指标下人类测试者平均为 48%。

官方 Harness 会在每一步后丢弃模型的私有推理，并滚动截断较早历史；OpenAI 的 Responses API 保留推理状态，并在上下文变长时压缩历史。模型权重没有变化，改变的是它能否记住自己已经试过什么，以及长任务中怎样保留有效上下文。

### 核心判断

Agent 时代的基准正在从「测一个模型」变成「测一套系统」。模型、推理保留、上下文压缩、工具接口和 Prompt 只要改变一项，结果都可能显著变化。

这会制造一条真实张力：统一 Harness 更容易公平横向比较，却可能低估不同产品栈对模型能力的释放；厂商自带 Harness 更接近产品体验，却也更难排除定制优化和选择性报告。文章不必替其中一方裁判，重点是让读者知道排行榜数字不再能脱离运行条件单独阅读。

### 可用标题

- 《模型没换，两个设置让跑分从 13.3% 跳到 38.3%》
- 《同一个 GPT-5.6，为什么换个 Harness 就强了近 3 倍》
- 《AI 排行榜开始测的，可能不只是模型》

### 事实边界

- 38.3% 来自 OpenAI 自建 Responses API Harness，不是 ARC Prize 官方榜单替换值。
- 「近 3 倍」指 38.3% 相对 13.3%，不是与半私有集 7.8% 混比。
- 结果证明上下文与推理状态会显著影响表现，不能外推成 GPT-5.6 的一般能力提高 3 倍。
- 需要同时呈现 ARC 统一 Harness 追求可比性的理由，避免把厂商解释直接写成基准失效。

## 第三选择：一个模型上线后，先去改了自己运行的底层代码

### 新事实

OpenAI 7 月 29 日称，GPT-5.6 Sol 通过 Codex 分析生产负载与路由，自动改写、优化生产 GPU Kernel；这些工作与更广泛的 Kernel 改进合计让端到端服务成本下降 20%。

OpenAI 还称，GPT-5.6 Sol 为自己的小型 Draft / Speculator Model 设计并运行数百次实验，监控训练，在硬件故障和训练不稳定时介入，最终把 Token 生成效率提高超过 15%。同一套 Agent Harness 还用延迟发现工具、限制工具输出和追加式上下文提高 Prompt Cache 命中。

### 核心判断

前沿模型公司的成本优势开始与模型能力形成反馈回路：更强模型帮助改 Kernel、路由、缓存和 Speculative Decoding，降低推理成本；更低成本又允许更多调用、实验和产品使用。竞争不再只是「谁训练出更强模型」，还包括「谁能用模型更快地优化承载模型的系统」。

### 可用标题

- 《GPT-5.6 开始替自己省算力：OpenAI 称服务成本降了 20%》
- 《一个模型上线后，先去改了自己运行的底层代码》
- 《AI 公司新的成本武器：让模型亲手优化推理栈》

### 事实边界

- 20% 与超过 15% 都是 OpenAI 自报，没有独立审计、原始成本基线或完整实验数据。
- 不能把这写成模型脱离人类和验证系统后「自主进化」；OpenAI 明确提到生产流量分析、验证工具和整体效果检查。
- Kernel 降本、Speculator 提效和 Harness 优化是三层不同工作，不把各百分比相加。

### 来源

- P0 厂商自报：[OpenAI：How GPT-5.6 fuses frontier intelligence with frontier efficiency](https://openai.com/index/gpt-5-6-frontier-intelligence-efficiency/)

## 高价值更新：MCP 最大一次改版已经从「等正式版」变成可写

7 月 28 日版本的正式规范页、变更日志和版本化 Schema 已经上线，前轮雷达里的等待条件满足。

最值得写的变化不是又加了多少能力，而是 MCP 主动删掉协议级会话：移除 `Mcp-Session-Id`，移除 `initialize` / `notifications/initialized` 握手，每个请求自行携带协议版本和客户端能力，并新增 `server/discover`。这让服务更接近普通无状态云基础设施，便于负载均衡、缓存、扩缩容和故障恢复，但也是一次需要客户端与 SDK 迁移的破坏性变化。

可用标题：《MCP 最大一次改版正式落地：它先把「会话」删了》

事实边界：规范正式发布不等于生态已经完成迁移；旧版客户端、SDK 与服务端的兼容节奏需要另查，不能写成一夜切换。

来源：[MCP 2026-07-28 规范](https://modelcontextprotocol.io/specification/2026-07-28)；[关键变更](https://modelcontextprotocol.io/specification/2026-07-28/changelog)；[版本化 Schema](https://github.com/modelcontextprotocol/modelcontextprotocol/tree/main/schema/2026-07-28)。

## 两个观察与一个并题

### OpenAI 免费向学术研究者开放 10 万个名额

OpenAI 计划到 2027 年向 10 万名学术研究者提供免费访问，2026 年夏季先开放 1 万人，最多四人协作。可写的不是公益数字本身，而是前沿模型厂商把科研工作流作为长期产品入口与领域反馈来源。后半句属于编辑推断；官方同时表示该产品数据默认不用于训练，不能偷换成「用免费名额换训练数据」。

来源：[ChatGPT for Academic Researchers](https://openai.com/index/chatgpt-for-academic-researchers/)。

### GitHub 代码审查正式调用 Agent Skills 与 MCP

GitHub 7 月 29 日宣布，Copilot Code Review 对 Agent Skills 和 MCP 的支持全面可用。团队可用 `.github/skills/.../SKILL.md` 固化审查标准，用 MCP 从工单、文档和服务目录读取上下文；MCP 工具调用被限制为只读，生成的评论会标注是否使用了 Skill 或 MCP。

这条最有价值的不是单独写一篇产品新闻，而是补进既有 Skill / Agent 工作流选题：AI Code Review 的差异正在从模型能力转向组织能否把自己的规则和上下文写成可执行的审查合同。

来源：[GitHub Changelog](https://github.blog/changelog/2026-07-29-copilot-code-review-agent-skills-and-mcp-now-generally-available/)。

### Grok Voice 与 Lyria 3.5 先观察

- **Grok Voice Think Fast 2.0**：xAI 主打边说边推理、在一句话结束前调用工具，定价为每分钟 0.08 美元。与前轮「语音成为 Agent 控制入口」重合，且转化率、客服解决率等缺少公开数字，等真实通话和工具调用实测。[xAI 官方发布](https://x.ai/news/grok-voice-think-fast-2)
- **Lyria 3.5**：Google 宣布提高音乐性、歌词、演唱与发音，并增加节奏、时长控制。当前主要是厂商能力声明，缺少模型卡、权利边界变化和独立对比，除非能做同 Prompt 实测，否则只进产品更新。[Google 官方发布](https://blog.google/innovation-and-ai/models-and-research/google-labs/lyria-3-5/)

## 本轮不建议另开

- **把 FCC 写成「美国全面封杀中国机器人」**：文本范围是所有外国生产设备，且存在 Conditional Approval；标题虽然更刺激，但会同时错在对象和程度。
- **把 ARC-AGI-3 结果写成「OpenAI 证明基准造假」**：当前是厂商对统一 Harness 的技术异议，不是基准方承认错误，也不是独立复现实验。
- **把 GPT-5.6 降本写成「AI 已经可以自我进化」**：这是有人类目标、生产数据、工具权限和验证体系约束的系统优化。
- **再写一篇泛泛的语音 Agent 新时代**：Grok Voice 新品与 7 月 26 日雷达已有判断高度重合，新增价值要靠真实通话任务而不是厂商榜单。
- **追更 Apple、Meta、Anthropic 的旧发布**：本轮没有发现比 7 月 28 日两份雷达更强、且能改变既有排序的一手新信号。

## 下一步建议

若锁定主推，先建 `fcc-foreign-robot-access` 内容包，并补完三项核查再动笔：

1. 从 FCC 附录逐字摘出正式定义、排除项和既有授权处理规则。
2. 查询代表性扫地机器人、割草机器人和四足机器人的 FCC 授权记录，不用类别推断代替具体型号事实。
3. 补中国厂商美国市场份额、出货量和企业回应，区分第三方统计、媒体报道与厂商表态。

若希望当天完成一篇证据链更短的稿，改选 ARC-AGI-3 Harness 题；它只需再补 ARC Prize 对统一 Harness 的正式回应或方法说明，即可进入结构工作坊。
