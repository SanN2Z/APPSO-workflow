# Editorial review checklist

Use this file for X and cross-platform checks. WeChat uses [wechat-editorial-gates.md](wechat-editorial-gates.md) as its single final checklist.

## Shared

- Verify time-sensitive facts, names, quotes, dates, numbers, and comparison settings.
- Separate fact, vendor self-report, third-party result, and inference.
- Check local image paths, rights, credentials, temporary paths, and personal information.
- Keep status below `ready` while a blocker remains.

## X final

- One central idea per post.
- Current source or original-post context is available.
- CTA is relevant and not repetitive.
- No bulk or deceptive engagement pattern.
- External actions remain dry-run until explicitly approved.
