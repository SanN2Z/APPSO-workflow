# INSIGHT-001 证据说明

## 脱敏来源

用户观察到自己擅长从具体工作上升到跨层判断，但也意识到风险：判断可能比证据、产品和稳定交付跑得更快。因此，本记录只保留一个可由当前仓库检验的机制问题：

> 反馈资产只有在自由判断、编辑取舍和硬门检查分层后，才会减少同机制返工吗？

原对话中的个人比较和职业上限判断不进入公司知识库，也不作为实验结论。

## 当前证据判断

证据等级升到 `E1`，但方向是对原宽命题的反例，不是对三层流程的效果证明：

- [文章 brief](../../../../../微信公众号/内容/2026/07/ai-agents-real-world-loss/brief.md) 已提出「反馈闭环所有权」命题，但提出命题不等于验证命题。
- [本轮复盘](../../../../../微信公众号/内容/2026/07/ai-agents-real-world-loss/retrospective.md) 的 `DLV-002` 已指出「接触反馈不等于拥有闭环」，仍只有一个直接案例。
- [SOP 变更台账](<../../../../运营/复盘/SOP 变更台账.yml>) 证明反馈已经产生 Skill、脚本、模板和门禁，但历史记录没有统一的人工时间、触发机会和复发率，不能据此计算复利效果。
- [DeepSeek Harness 稿复盘](../../../../../微信公众号/内容/2026/08/deepseek-harness-internal-test/retrospective.md#fb-006) 记录了同一稿在判断工坊、钩子、叙事、人话和事实边界规则下多轮返工后，仍被用户判断为「没什么营养和价值」；其中「评测条件未完整公开」这一硬门限定被写成读者不关心的完整章节。

这个案例足以反对「只要把反馈做成更多规则，质量就会自然提高」，也支持把原命题缩窄为三层假设。它没有控制模型版本、执行顺序、研究投入和操作者学习效应，因此不能证明旧 SOP 必然导致低价值，也不能证明 v4.0 已经有效。

## 首轮前瞻实验

2026-08-02，以《AI 提不出下一个「王的猜想」》运行 `EXP-001`。题目、受众、材料包、模型条件、禁读范围、分支映射、10 分量表、+2 分增量阈值、8 分绝对阈值和事实护栏均在写作前冻结。

- A：当前内容工作流 v4.0。
- B：v4.0 加文章编译器 0.1，先做素材角色卡、问题阶梯、场景包和章节依赖检查。
- 两位写作者与盲审均使用 `fork_turns:none`；盲审不知道映射。
- 结果：A = 10 / 10，B = 10 / 10；盲审同分选择 B，信心为中；两稿重大事实阻断项均为 0。
- 决定：`neutral`。B 没有达到预先冻结的 +2 分阈值，因此不支持推广；同分也不足以证明干预无效。

这次结果至少否定了一条操作假设：不能因为实验稿「读起来稍顺」就把新流程写进 SOP。当前 v4.0 对照稿在同一材料包上也能形成完整的问题链。后验检查还发现，量表已经封顶，材料包又按接近成稿论证的顺序排列，两者都会压缩可观察分差。

## 第二轮前瞻实验已冻结

2026-08-02，以 DeepSeek Harness 定向邀请开源开发者参加内测为独立案例冻结 EXP-002。

- 12 张材料卡按 SHA-256 摘要排序，不携带时间线或预期论证顺序。
- 题材没有「电梯」或「针」一类现成强场景；正文固定为 900—1600 字的短观察，不允许材料不足时硬凑长篇。
- 对照仍为现行 v4.0；干预压缩为材料取舍、3—5 级问题链和删节／换序检查，计划上限为 800 个中文字符。
- 主指标改为两名独立盲审的一致配对偏好，不再使用会同时打满的整数总分。
- 本轮没有人类写作者，人工分钟预先固定为 null；不拿 Agent 墙钟时间冒充效率数据。

## 第二轮结果

两名独立盲审都选择 B，信心均为中。揭盲后：

- A：v4.0 加文章编译器 0.2。
- B：纯 v4.0 对照。
- 两稿重大事实阻断项均为 0。
- A 的材料取舍被两名评审认为略好，编译计划为 488 个非空白字符，低于 800 字上限。
- B 的必要阅读顺序被两名评审一致认为更强。

两位评审给出了同一理由：A 先回答「为什么找同行」，后面的模型卡、外部接入和团队招聘就成为可删的进度支线；B 先让读者看见 Harness 会制造哪些故障层，再由「谁有能力定位这些故障」逼出 GitHub ID 与开源代表作门槛。该差异落在预注册指标，不是语气偏好。

因此 EXP-002 判为 contradicts。当前证据反对文章编译器 0.2 的显式问题链实现：它会把主题上相邻、因果上可拆的问题用箭头包装成连续结构。它不证明所有写前规划无效。

## 远期命题

「正当拥有反馈闭环的人或组织会形成更强长期复利」可以作为长期研究方向，但必须经过更多操作者、任务类型和迁移环境验证。在当前实验通过前，不把它写成稳定判断；即使公众号机制通过，也不能直接外推为个人职业结论。
