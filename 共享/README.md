# 共享目录边界

`共享/` 只放两个平台都会复用的材料，不替代单篇内容包。

- `品牌/`：账号简介、公开署名、品牌视觉和已确认的长期表达。
- `研究/`：跨平台可复用的事实包、来源笔记和[洞察实验室](研究/洞察实验室/README.md)。单篇文章的完整证据仍保留在该内容包的 `sources.md` 和 `research/`；洞察卡只链接原始案例，不复制反馈或受限资料。
- `素材/`：可跨内容包复用且权利清楚的素材；使用时复制进目标内容包并登记，正文不得引用包外路径。
- `模板/`：新内容包骨架，不存活跃稿件。
- `运营/`：选题池、日历、SOP 和跨平台数据复盘，是状态索引，不覆盖 `draft.md` frontmatter 或 `publish-record.md`。

不要把公众号成稿直接搬给 X；事实可以共享，成稿必须按平台重写。
