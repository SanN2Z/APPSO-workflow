更新日期：2026 年 10 月 27 日。这里只导航，链接目标负责规则正文；文件职责见 [SOP 架构](README.md)。

## 一篇稿怎么做

先确认平台、账号、当前阶段与本轮交付物，再组合需要的模块：

| 账号／平台 | 配置入口 |
|---|---|
| 个人公众号 | [公众号账号配置](../../../微信公众号/CONTEXT.md) |
| APPSO 公司稿 | [APPSO 内容生产 adapter](<../../../APPSO-数字资产/03-SOP/APPSO 内容生产 SOP.md>)；视频产品体验、Hunt Good 等专项从其任务菜单进入 |
| X | [X 平台指令](../../../X/AGENTS.md)；独立写成适合该平台的内容 |

1. **定任务。** 用 [self-media-ops](../../../.agents/skills/self-media-ops/SKILL.md) 选择最短路径；本轮是调研、制作、成文、改稿还是交接，按当前要求决定。已有内容包继续用原记录。
2. **取得材料。** 查资料与原始配图同步进行；产品体验按专项完成真实测试、作品与过程取材。编辑另制配图按用途进入生图模块，被测产品输出保留真实来源。
3. **写与改。** 快讯、分析和产品体验使用各自任务要求；品牌声音由账号配置决定。局部反馈定位到小节、镜头或图片，只改指定范围。
4. **完成当前载体。** 用户已指定 HTML、ZIP、飞书或其他交付物时执行该要求；未指定时使用目标平台的交付默认。公众号预览、公司浏览器排版和实际发布分别进入相应阶段，不把交付默认当成外部写入授权。
5. **留记录。** 来源、输入、作品、费用和反馈留在目标内容包；可复用的偏好与流程变化按作用范围回填唯一真源。

完整流程、状态和事实门：[内容工作流](内容工作流.md)。

## 桌面材料如何使用

桌面 `公众号` 文件夹作为来源留存。内容相同的规范和 Logo 只保留一个仓库真源；快讯参考原文与去 AI 味 Prompt 已存入[来源目录](../../参考/桌面公众号流程/README.md)。完整来源、SHA-256 和执行入口由[工作流输入清单](../../../tools/workflow-source-assets.json)登记。

参考原文不自动成为写作指令。快讯原文中的固定字数、热梗频率和强行反转，与现在的写作要求不一致，实际执行使用上表的快讯 Prompt。

2026-09-07，主理人明确要求这些流程、Prompt 与工具统一进入私有仓库。换机不用再从桌面找原件；不需要逐份重新确认分级。账号凭据、登录态与运行缓存仍由本机配置。

## 需要再打包时

提交后运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/workflow.ps1 export-workflow
```

在 output 下生成工作流源码包、1.10.3 插件包和带提交号的校验记录。只打包已提交文件，不包含文章正文、录屏、依赖或登录配置。工作流包用于备份和查阅；新机器完整安装仍优先私有 Git clone 后运行 bootstrap。插件包解压后，直接加载能看到 manifest.json 的那层目录。
