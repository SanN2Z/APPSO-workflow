# SOP 地图

普通任务只从[《内容工作流》](内容工作流.md)进入。其他模块按触发条件加载，不串成一条固定长链。

| 任务 | 入口 |
|---|---|
| 选题、调研、写作、审校 | [`内容工作流.md`](内容工作流.md) |
| 生图或图片编辑 | [`Image2 生图工作流.md`](<Image2 生图工作流.md>) |
| Git 整理与提交 | [`Git 提交与仓库整理 SOP.md`](<Git 提交与仓库整理 SOP.md>) |
| 反馈复盘 | [`content-retrospective`](../../../.agents/skills/content-retrospective/SKILL.md) |
| 长期洞察实验 | [`insight-to-asset`](../../../.agents/skills/insight-to-asset/SKILL.md) |
| APPSO 专项 | [`APPSO-数字资产/03-SOP/`](../../../APPSO-数字资产/03-SOP/) |
| 公众号交付 | [`wechat-publishing.md`](../../../.agents/skills/self-media-ops/references/wechat-publishing.md) |

规则只在一个文件维护。核心流程放这里；平台、品牌、栏目、视觉风格和发布工具留在各自 adapter；案例和原始反馈留在内容包。
