# 中文 AI 表达模式广搜与禁用边界

日期：2026 年 8 月 3 日

范围：微信公众号中文科技解释稿、观点稿与产品稿的表达层。事实、引语、数字、身份与证据边界继续由既有 fact gate 负责。

状态：项目配置；用户反馈驱动；效果待真实稿件验证。

## 结论

公众号表达优化的主损失不是论文里的通用检测准确率，而是主理人和真实读者对成品的直接反馈。主理人明确说「不喜欢」已经构成有效验收失败，不必先积累跨稿统计、解释完整机制或等待学术共识。先删改，后复盘机制；读者数据再决定扩大、收窄或解除。

外部材料的作用相应下调：中文社区和 GitHub 用来扩大候选池，学术论文用来提醒我们关注组合特征、体裁差异与误判边界。任何词式禁用都只是本项目的传播与审美配置，不构成「作者使用了 AI」的证据。

执行真源是 [wechat-expression-library.yml](../../../.agents/skills/self-media-ops/references/wechat-expression-library.yml)。本文件保存调研依据、取舍和反例，不复制完整机器可读条目。

## 决策权重

1. 用户在真实稿件中的修改意见、明确喜好与冷读反馈：决定当前项目是否禁用。
2. 不同内容包反复出现的内部反馈：验证读者伤害、修复方向与适用范围。
3. 中文社区、编辑经验和 GitHub 规则库：发现相邻模式，进入候选池。
4. 学术研究：说明模型文本可能有哪些组合差异，以及为什么静态词表不能承担作者身份判断。

这套排序允许一次明确厌恶直接产生项目禁令。外部高共识能提高候选优先级，却不是用户意见生效的前置条件。

## 本轮采纳

公众号分析稿启用 `PROJECT-WECHAT-AI-LEXICON-001`：24 组表达全部默认不得原样进入未加引号的作者正文，不再保留常规语义复核池。命中后须删除、具体改写，或记录窄豁免。

| 组别 | 代表词式 | 主要损失 | 默认修复 |
|---|---|---|---|
| 注意力与舞台指令 | 「值得注意的是」「接下来看看」「你可能会问」 | 作者先指挥读者，再迟交内容 | 直接写事实、冲突或下一步 |
| 空权威与预制确定性 | 「研究表明」「答案很明确」「不难看出」 | 用语气替代来源和推理 | 补来源与成立条件，或删除 |
| 万能背景与报告收尾 | 「随着……快速发展」「综上所述」 | 开头、结尾都可跨题移植 | 从事件进入；以边界或下一信号收束 |
| 空对称与机械序号 | 「一方面……另一方面……」「首先、其次、最后」 | 为完整感制造并列 | 只保留真实比较尺度、依赖或步骤 |
| 意义膨胀 | 「重新定义」「里程碑」「改写格局」 | 程度词遮住实际变化 | 写清主体、动作、指标、成本和证据 |
| 伪层级与伪揭晓 | 「真正的问题在于」「答案藏在……里」「这就是……的力量」 | 表演洞察或金句 | 直接写具体决定、关系或后果 |
| 递进与否定对比 | 「不仅是 A，更是 B」「不是 A，而是 B」「看似 A，实则 B」 | 用对称句替代论证，虚构稻草 A | 正面陈述 B；必要时写范围或权重 |
| 推断与本质化脚手架 | 「这意味着」「关键在于」「归根结底」 | 先宣布推断或决定性变量，证据和对象仍为空 | 直接写证据支持的对象、条件和结论范围 |
| 背景与解释脚手架 | 「在此背景下」「基于此」「换句话说」 | 用连接词代替前后句的具体依赖 | 写出哪项事实造成哪项约束；重复释义直接删除 |
| 业务抽象与装饰隐喻 | 「赋能」「闭环」「底层逻辑」「落地」「账单」「交卷」 | 抽象词和隐喻把动作、责任及返工包装成文章感 | 写清参与者、输入、动作、输出和验收；字面事实走豁免 |
| 万能未来 | 「未来可期」「让我们拭目以待」「才刚刚开始」 | 用乐观口号伪造收束 | 写待验证条件或下一可观察信号 |
| 聊天机器人残留 | 「希望以上有所帮助」「如果你愿意，我可以……」 | 把对话服务脚手架带进文章 | 删除寒暄和后续服务承诺 |
| 罐装共情 | 「稳稳地接住」「被看见、被理解」「温柔而坚定」 | 用批量安慰冒充具体理解 | 写清处境、限制、动作与减负结果 |

其中 `WX-EXPR-015` 的「不是 A，而是 B」及其变体是本轮明确禁用重点。即使 A 与 B 逻辑上互斥，也优先改成正面句，例如把「错误不是出在读取，而是出在写回」改成「读取日志正常；错误发生在写回阶段」。只有逐字引语、规范原文或改写确实损失精度时才申请豁免。

## 原 6 组复核项已升级为默认禁用

主理人冷读词库后明确指出，原复核池里的「关键在于」以及隐喻式「账单／交卷」本身已经是一眼可辨的 AI 文章腔。依照本项目「一次明确厌恶即可形成禁用」的配置，推断连接器、本质化框架、背景连接器、解释框架、业务抽象词和非字面隐喻链 6 组全部进入公众号默认禁用。

复核问题现在只用于决定「直接改写」或「记录窄豁免」，不再产生静默放行。真实付款账单、考试现场交卷、官方名称、来源原话、法律／标准原文及精度关键术语仍可保留；它们必须按字面或来源用法记录，不能反向恢复装饰性作者表达。

## 扩展观察池

本轮还收集到反问引导、伪现场共识、连续模糊程度词、过度齐整的三项排比、通用人生格言、假口语颗粒和标题式名词句等个人厌恶模式。它们先进入观察池；主理人后续一句明确否定即可升级为项目禁用。

没有采纳单独禁用破折号、冒号、短句或第一人称，也不通过随机口语、错别字、网络梗、打乱语序来规避检测器。这些做法会制造新的表演感。

## 反例与豁免

「不是……而是……」是正常汉语结构，也能承担事实排除和术语消歧。Darkthread 对 22 年个人文章的自查找到 4,036 篇中 135 篇使用相关结构，说明真人会用；问题通常是高密度、连续段落复用和用它制造不存在的反方。这个反例不推翻项目禁令，只说明禁令属于审美与传播选择，不是作者身份鉴定。

可申请的窄豁免包括来源原话、官方名称、界面文字、法律／标准／规范原文、必须逐字准确的术语、按本义使用且改写会损失准确性的字面事实或具体对象名称、改写会损失精度的事实排除，以及具有真实依赖关系的操作步骤或法规条件。每次须记录条目 ID、完整句、即时上下文、豁免类型、不可替代的信息任务和批准人；能准确改写时不豁免。

## 中文社区与编辑观察

- [中国社会科学网：智能写作的「AI 味」问题](https://www.cssn.cn/skgz/bwyc/202607/t20260703_6057355.shtml)提到工整空泛、模板结构、固定连接词和重复总结。
- [少数派：你写的文章？都是 AI 味](https://sspai.com/post/106564)列出否定对比、机械序号、递进升级和对话助手尾巴，也提醒禁词不能修复长文结构。
- [少数派：我们如何看待「用 AI 写」和「写 AI」的文章](https://sspai.com/post/99838)把判断重点放回内容质量、事实和对读者的尊重。
- [少数派作者披露](https://sspai.com/post/107066)把若干高风险对比句视为自己的稳定风格，构成静态词表误伤的反例。
- [LINUX DO：AI 味规则讨论](https://linux.do/t/topic/1996748)记录用户对连续否定对比、报告词、总结章和后续服务话术的厌恶；属于社区经验。
- [LINUX DO：否定对比讨论](https://linux.do/t/topic/2474627)同时包含「像翻译腔」和「只禁表面会保留同一逻辑」两类意见。
- [V2EX 讨论](https://global.v2ex.com/t/1031838)把机械序号和总结词视为早期可见信号，也有人指出检测器容易被规避。
- [朱宥勋：AI 感经典句型](https://www.youtube.com/watch?v=9uuX6cb81C8)把否定对比视作明显语感来源，同时说明它原本承担区分与定义功能。
- [Darkthread：个人语料自查](https://blog.darkthread.net/blog/ai-slop-not-but-pattern/)提供真人长期语料的频率反例。
- [中文维基百科：AI 生成文的特征](https://zh.wikipedia.org/wiki/Wikipedia:AI生成文的特徵)汇总中文注意词、否定排比和三项结构，并提醒这些现象不能单独证明 AI 来源。

知乎、B 站、TRAE、SEO 博客和台湾内容营销站还出现大量相似清单。它们常夹带工具营销、检测器规避或未经验证的比例，只作为个人厌恶池和候选扩展。

## GitHub 与开源规则

- [pencil20388-eng/stop-slop-zh](https://github.com/pencil20388-eng/stop-slop-zh)提供更激进的中文清单；随机口语化和标点禁令未被本项目采纳。
- [Norman-bury/research-writing-skill](https://github.com/Norman-bury/research-writing-skill)收录机械序号、总结和注意力框架，但其学术写作体裁只作交叉印证。
- [Narcooo/inkos](https://github.com/Narcooo/inkos)说明小说社区也会直接禁固定句式、说教和整齐结构；题材疲劳词不自动移植到科技媒体。

## 学术边界

- [Zhu 等，CCL 2023](https://aclanthology.org/2023.ccl-1.46/)比较中文人类与 ChatGPT 文本的 159 项语言特征，差异覆盖词汇、句法和衔接。
- [Li 与 Zhang，CCL 2025](https://aclanthology.org/2025.ccl-1.64/)在 463,382 条微博评论中发现长度、停用词、错误波动、标点和情感词等组合差异，并强调中文特征库需要动态更新。
- [Kim 等，ACL 2024](https://aclanthology.org/2024.acl-long.298/)发现真人文本的篇章结构变化更大，支持把审校重点从换词扩展到段落与论证组织。
- [Russell 等，ACL 2025](https://aclanthology.org/2025.acl-long.267/)显示高频使用 LLM 的写作者会结合词汇、公式化结构和通用乐观结尾识别英文样本；英语结果不能直接变成中文词表。
- [Xia 等，EACL 2026](https://aclanthology.org/2026.eacl-long.307/)显示检测器跨提示词、模型和领域时明显退化。
- [Human–LLM Coevolution，ACL 2025](https://aclanthology.org/2025.findings-acl.657/)观察到人类会回避已被指出的 LLM 偏好词，说明表达信号会随社会使用变化。
- [Schuster 等，Computational Linguistics 2020](https://aclanthology.org/2020.cl-2.8/)讨论风格测量在机器文本与虚假信息判断上的限制。

学术材料只提供边界：表达禁用服务传播成品，不计算 AI 概率，不评价诚信，不以检测器分数验收。
