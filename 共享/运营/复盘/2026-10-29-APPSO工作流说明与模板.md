## 本轮采用

- 根 README 面向读者介绍功能、业务场景和整体结构，嵌入两张实际 Image2 配图。安装命令、配置参数、清单字段及详细操作统一放入 `docs/appso-workflow/使用与技术附录.md`，具体规则链接原真源。
- 视频制作说明覆盖官方 CLI 生成、Web 工作台实测、任务 ID 查询与回收、逐镜连续性、整片与精选片段、全局过程图和真实费用记录。
- 图像与视频各提供一份 HTML 模板，统一 `media-review` 入口接收相对路径清单，复制实际素材并生成可离线阅读的 ZIP。文章 Markdown 仍使用原有渲染与交付工具。
- Image2 封面与架构图作为文档插图保存，使用项目已有风格与品牌输入，标记 AI 生成并登记来源。
- 工具、模板与依赖入口登记到已有工具链；业务说明保留 X、外部模型、PDF／图片工具和独立科研入口的作用范围。
- README 先展示真实图像成品与稿例；各项功能说明具体任务、使用场景和交付物。图片部分区分原图、笨拙涂鸦与信息图，给出可调整的正文配图方案，沿用至少两类视觉的要求。命令、配置与安装细节继续放在附录。

本轮不修改内容正文或原有未提交任务。工作流文档的配图为明确要求的版本化说明资产；视频样片、生成的审阅包和浏览器检查结果留在本机输出目录。
