## 真源规则

1. 新增的 APPSO 方法资产与 SOP 以本目录为入口。
2. 公众号内容包仍放在 `微信公众号/内容/`，不把单篇成稿复制进方法库。
3. 已存在的高敏感材料只在[内部资产索引](<00-治理/内部资产索引.md>)登记原路径，不复制公司终稿或逐条反馈。
4. 公开样本研究可以保存方法总结，不保存未经许可的完整参考文章。
5. 公司稿与个人稿只共享已核事实，不共享成稿表达、图片、独特结构和结尾。
6. 密码、Cookie、Token、API Key、验证码、登录态和完整请求头永不入库。
7. 经明确授权、Private 远端已核且凭据与运行态审计通过的公司内部工具，以 `tools/company/<tool>/<version>/` 为唯一 Git 真源；这项例外不覆盖公司终稿、后台数据或浏览器会话。

## 使用原则

- 原始资料不直接改写；需要修订时新建派生文档，并在资产台账记录来源。
- 内部方法可以用于公司工作；改编为个人账号内容前，必须重新立题、重新写作并重新处理视觉权利。
- Logo、设计文档和公司 Prompt 目前均按「内部参考」处理，不代表已经获得公开转载或商业使用授权。
- 每次将单稿经验升级为 SOP 前，先判断它是否跨稿有效；只对一次返工有用的细节留在复盘，不写进总流程。
