# 公开科技媒体衍生语料

更新日期：2026 年 7 月 25 日
分级：`public-derived`

这里用公开科技媒体样本校准本项目的选题、结构、信息密度和审校 Skill。它不是文章全文库，也不是模仿某个媒体或作者的词库。

## 「训练」在这里指什么

本项目所说的「语料训练」，只指：

- 用公开 URL 建立可追溯样本目录；
- 用确定性程序计算段落、句子、小标题、图片和篇幅等结构统计；
- 由编辑人工标注开头任务、材料关系、证据类型、限制处理和结尾任务；
- 用这些派生结论更新项目 adapter、检查表和回归案例。

它不指模型预训练、微调，也不把第三方正文送入训练集。爱范儿当前 `robots.txt` 明示 `ai-train=no`，并把内容使用限定为 `reference`；因此 APPSO／爱范儿样本只用于人工编辑参考、公开链接索引与不含正文的派生统计，不得用于模型训练。

## 资产分层

| 层 | 文件 | 可以保存 | 不保存 |
|---|---|---|---|
| 来源策略 | `source-registry.yml` | 官方入口、robots 状态、采集边界、复核日期 | Cookie、登录态、绕过方法 |
| 元数据目录 | `metadata-catalog.yml` | 媒体、标题、URL、日期与发现入口 | RSS description、正文、摘要 |
| 候选池 | `pilot-urls.txt` | 明确选择的公开文章 URL | 自动发现的无限链接 |
| 衍生记录 | `records.jsonl` | 标题、作者、日期、栏目与结构统计 | 正文、HTML、摘要、引文、词频、n-gram |
| 人工标注 | `editorial-annotations.yml` | 稿型、开头任务、论证关系、限制与结尾任务的转述标签 | 固定口头禅、独特比喻、原段落、收束原句 |
| 聚合结论 | `style-findings.md` | 跨样本稳定方法、反例、适用范围 | 「某媒体官方 SOP」式误称 |
| 运行审计 | `run-receipts/` | 时间、策略哈希、状态码和稳定错误码 | 响应正文、异常页面片段 |

首批 `records.jsonl` 只是管线验收样本，不足以得出媒体级结论。每个媒体、每种稿型至少需要 10 篇不同作者或不同日期的合格样本，才能形成候选观察；跨稿型、跨媒体或经编辑 DIFF 验证后，才考虑更新 SOP。

## 执行流程

```text
公开入口与 robots 复核
→ 人工选择 URL 与稿型
→ dry-run 检查域名、路径和策略
→ 低频抓取，正文只在内存形成结构统计
→ 输出白名单与零正文泄漏校验
→ 人工标注信息任务，不抄句子
→ 按媒体、稿型、作者和商业属性分层比较
→ 在新稿上做前后版本回归
→ 有跨稿证据后更新表达库或项目 adapter
```

抓取器入口见 [`tools/derived_corpus`](../../../../tools/derived_corpus/README.md)。联网动作默认 dry-run；只有显式 `--execute` 才请求页面。工具不递归跟链接、不登录、不执行 JavaScript、不下载图片、不碰付费内容、不提供忽略 robots 或降低限速的开关。

## 样本选择规则

1. 先按稿型抽样，不把快讯、论文解释、产品实测、商业合作稿和观点稿混成一个平均文风。
2. 同一事件尽量选择不同媒体各 1 篇，比较选题角度、事实顺序、证据密度和限制处理。
3. 标记作者、栏目、同步转载和可能的商业合作属性；来源属性不明时不把它当风格正例。
4. APPSO 的既有 25 篇研究继续以 [`APPSO 近 25 篇样本分析.md`](../APPSO%20近%2025%20篇样本分析.md) 为证据底座，不复制正文。
5. 不收集、复用或生成参考媒体的固定口头禅、独特比喻、标题模板和结尾原句。
6. 语料观察只能生成「候选」。实际稿件仍以事实、读者问题、作者判断和编辑反馈为准。

## 与表达库的关系

[`wechat-expression-library.yml`](../../../../.agents/skills/self-media-ops/references/wechat-expression-library.yml) 是表达审校候选库；本目录是公开样本证据与反例池。二者分工如下：

- 表达库问：「这句话是否只有套式功能，删掉会不会丢信息？」
- 衍生语料问：「高质量稿件怎样组织事实、问题、证据、限制和结尾？」

不会因为参考媒体使用过某个词就自动放行，也不会因为某个词在表达库里就自动判错。

## 当前状态

- APPSO／爱范儿：已有 25 篇公开样本的人工结构归纳；自动流程只补官方 RSS 元数据，不摄取正文。
- 机器之心：公开列表和 sitemap 用于元数据目录；文章正文需要客户端加载，v1 不调用隐藏 API 或执行 JavaScript。
- 量子位：已确认公开 RSS 与文章页，首批 3 个显式 URL 用于结构管线验收。
- 少数派、36Kr：当前只解析官方 RSS 的标题、URL、日期和作者／栏目，主动忽略介绍或正文。
- 新智元：官方域名为 `aiera.com.cn`；本轮 robots 与 RSS 均返回 500，只允许低频 sitemap 元数据差分，不自动读取正文。
- 所有站点在再次采集前重新读取 `robots.txt`；规则变化时以最新公开声明为准。
