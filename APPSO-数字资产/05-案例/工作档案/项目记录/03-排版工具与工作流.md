## 问题与留下的改动

| 使用中遇到的问题 | 已留下的处理 | 验收边界 |
|---|---|---|
| 正文缩进影响头图，手动补图后难以单独调整 | 正文文字与图片两端 16 px，头尾图独立为 0；独立段落保留编辑空间 | 本地浏览器检查已有记录，仍需实际公众号粘贴回看 |
| 飞书页面读取器未连接 | 页面脚本注入、连接探测和明确错误提示 | 本地连接测试不能代替所有飞书页面实测 |
| GIF 头图托管失败 | 增加原始 GIF 文件粘贴路径、回退诊断与下载入口 | 用户日志仍显示头图未确认成功，不能写成已解决 |
| 23 张源图却统计出 44 个图片节点 | 区分可见图片与隐藏辅助节点 | 日志中有 22 张可见静态图，缺少的头图需单独判定 |
| HTML 预览能滑，复制到公众号后不滑 | 单独检查复制组件和粘贴结构 | 用户反馈后续可以滑动；实际保存、重开仍需单独验证 |
| 滑动框太矮 | 该稿视窗从 180 px 调整到 260 px | 属于这篇稿的取景选择，不把高度写成所有长图的唯一值 |

## 这项工作怎么记

扩展基于公司的原有工具。作者提出具体使用需求、提供错误日志并反馈实际效果；AI 协助定位问题、修改候选版本和运行本地检查。不将整个工具归为个人从零开发。

已有记录包含 14 项连接检查和 33 项隔离浏览器检查。这些验证针对本地候选版本，不代表当前账号的公众号托管链路全部通过。用户提供的日志里，`ok: true` 与 `imageUploadConfirmed: false` 同时出现，头图仍处于待处理状态。

用户接入飞书 MCP 后，当前已验证文档检索、正文读取和图片读取。创建、更新文档及向公众号交付不在此次读取验证范围内。
