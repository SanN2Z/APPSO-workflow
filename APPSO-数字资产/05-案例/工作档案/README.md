## 先留下这三段工作

**模型实测：把选题做成读者能看到的体验。** 从视觉任务入手，加入 APPSO Logo 游戏，再用录屏、信息图和外部材料组织文章。过程中也留下了模型归属纠正、选图返工和结尾重写的记录。

**够搭视频创作：把一次产品体验写成有材料支撑的稿件。** 飞书稿已有图片和视频附件引用。先保留原文入口和案例目录，具体制作过程以后按原始记录补齐。

**排版工具改进：把写稿后反复遇到的问题记成可验证的需求。** 正文两端缩进、头尾图独立编辑、长图滑动、GIF 托管，分别保留修改入口和验收结果。

这些记录不按完成度排座次。第三项仍有未解决的问题，也值得留下过程。

## 以后怎么续

一个项目结束后，用[项目记录模板](项目记录模板.md)补一张卡：原始入口、留下的成果、关键修改、还没解决的问题。优先链接已有文件，不再复制一套素材。

当某个经验在第二篇稿件里又出现，再判断要不要补进现有 SOP。[可复用经验](可复用经验.md)已链接对应规则，不另建一套生产流程。

确实发布后，再登记真实文章链接和日期。有实际后台数据时再补表现，暂时不估算阅读量、节省时长或效率提升。
