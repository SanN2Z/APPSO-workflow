# 爱范儿一键排版 v1.10.0｜安装与体验说明

## 安装或升级

1. 解压安装包，保留其中完整的 `extension` 文件夹。
2. 在 Chrome 打开 `chrome://extensions`。
3. 打开“开发者模式”。
4. 已安装旧版：先点击旧扩展的“移除”，再点击“加载已解压的扩展程序”。
5. 选择本次安装包里的 `extension` 文件夹。
6. 确认版本显示为 `1.10.0`，刷新已经打开的飞书和微信公众号页面。

## 题图选择

在飞书文档页打开插件，会看到“文章题图”：

- `自动`：默认选项。明确识别到 AppSo 稿件时使用红色「灵感指南」，其他稿件使用橙色爱范儿题图。
- `爱范儿`：无条件使用橙色 `DISCOVER THE NEXT`。
- `AppSo`：无条件使用红色「灵感指南」。

建议先用“自动”。如果页面显示的状态栏题图品牌不对，在收录前手动改选。已经收录后再切换，插件会要求重新收录，避免旧内容包继续使用错误题图。

## 使用

1. 在当前 Chrome 登录飞书，打开目标 Wiki 或文档。
2. 选择题图品牌和静态图画质，点击“收录当前飞书文档”。
3. 等待状态变为“已就绪”，确认状态栏显示正确题图。
4. 打开微信公众号测试草稿，并只保留一个公众号编辑器标签页。
5. 打开插件，一键覆盖并排版。
6. 检查正文第一张题图、标题、摘要、正文、引用和图片。

## 注意

- 自动判断依据是稿件内容，不读取作者部门；没有明确 AppSo 信号时默认爱范儿。
- 请先用测试草稿验收，不要直接覆盖待发布文章。
- 遇到问题时展开“查看技术详情”并复制，不要提交 Cookie、Token、密码等登录信息。
