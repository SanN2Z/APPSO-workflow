## 入库门

公司工具只有同时满足以下条件，才能进入本目录：

1. 用户或权利人明确授权保存到当前仓库。
2. 远端仓库已经确认是 Private。
3. 已扫描密钥、Token、Cookie、账号导出、浏览器 Profile、登录态、会话和运行缓存。
4. 已登记来源、版本、文件数、哈希、使用边界和已知问题。
5. 工具不包含来源不明的依赖包或远程执行代码；无法确认时停止入库。

这项规则不适用于公司终稿、后台数据、授权凭证、联系人或完整请求头。

## 目录合同

```text
tools/company/
  <tool>/
    README.md
    v<version>/
      原始版本文件
```

- 版本目录视为不可变来源。升级时新增 `v<version>/`，不原位覆盖旧版本。
- `.gitattributes` 对版本目录禁用文本行尾转换与自动空白修复，保证检出后的文件字节和登记哈希一致；仓库自有包装文档仍执行正常检查。
- 原始交付压缩包或重复目录不提交；规范副本才是 Git 真源。
- 浏览器 Profile、扩展本地存储导出、Cookie、登录态、日志、临时构建和缓存永不提交。
- 私有仓库中的保存不等于取得公开发布、再许可或迁移到个人项目的权利。
