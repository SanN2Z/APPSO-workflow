# 2026-07-05 Controversial Drafts

Status: ready for review. Do not publish without explicit confirmation.

## Frame

Goal: sharper, more controversial posts without becoming spam, hate, or fake
political agitation.

Use conflicts like:

- tool worship vs actual delivery;
- school-trained obedience vs market rewards;
- information access vs fake effort;
- county-town background vs global internet;
- engineer pride vs sales/content reality.

Avoid:

- explicit political mobilization;
- attacks on protected groups;
- unverifiable claims;
- "everyone is stupid except me" tone.

## Draft 1: School Trains Obedience

```text
很多普通人不是输给 AI。

是输给从小被训练得太听话。

老师说考试有标准答案。
公司说岗位有固定职责。
父母说稳定比折腾重要。

结果到了互联网，真正赚钱的东西全都没有标准答案：

选题、流量、转化、产品、信任。

AI 只是把差距放大了。

会听话的人，还在等教程。
会试错的人，已经开始收钱了。
```

## Draft 2: Technical People Are Too Clean

```text
技术人最吃亏的一点：

太干净。

总觉得东西要足够严谨、足够完整、足够高级，才配拿出来。

但互联网上先赚到钱的人，往往没那么体面。

他们先发。
先卖。
先被骂。
先拿反馈。

技术人还在打磨架构。
人家已经把第一个版本卖给真人了。
```

## Draft 3: AI Anxiety Is A Business

```text
AI 最先淘汰的不是不会用工具的人。

是把焦虑当学习的人。

收藏 100 个教程。
加 20 个社群。
买 5 套课。
每天看别人月入十万。

然后自己一个真实作品都没有。

这不是学习。

这是用信息流给自己打麻药。
```

## Draft 4: County Town Internet

```text
县城出来的人做互联网，有一个天然劣势：

没人告诉你，世界不是靠“努力”运行的。

很多机会不是写在招聘软件上。
不是写在课本上。
不是写在短视频鸡汤里。

它藏在英文信息源、支付渠道、工具链、圈子和执行速度里。

所谓信息差，本质上是入口差。
你连门在哪都不知道，当然只能卷体力。
```

## Draft 5: The New Literacy

```text
2026 年，新的文盲不是不会读字。

是只会消费中文互联网。

不会搜英文。
不会验证来源。
不会用 AI 拆问题。
不会把一个信息改写成产品、服务、内容。

每天刷短视频，以为自己在了解世界。

其实只是被喂养。
```

## Draft 6: Engineer Delusion

```text
程序员有一种幻觉：

只要我技术够强，市场自然会奖励我。

不会。

市场奖励的不是技术强。
市场奖励的是：

你解决了谁的问题；
你让谁相信你能解决；
你让谁愿意现在付钱。

技术只是底层能力。

不会表达、不会分发、不会成交，技术再强也只是库存。
```

## Draft 7: The Ugly Truth About Side Hustles

```text
副业最残酷的真相：

普通人真正缺的不是项目。

是承认自己暂时很普通的勇气。

很多人一上来就想做 SaaS、做 Agent、做自动化收入。

但他连连续 7 天发一个像样的内容都做不到。
连一个陌生人的真实需求都没问过。
连一次失败复盘都没有。

不是项目不行。
是自尊心太贵。
```

## Draft 8: Hidden Class Difference

```text
互联网最大的阶层差距，不是有钱没钱。

是默认选项不同。

有的人默认可以试错。
有的人默认必须稳定。

有的人默认英语信息源是日常。
有的人默认中文二手信息就是世界。

有的人默认工具是杠杆。
有的人默认工具是玩具。

AI 没有抹平差距。

它让默认选项的差距更快兑现。
```

## Draft 9: Stop Worshiping Prompts

```text
别再神化 Prompt 了。

Prompt 不是魔法。

一个没有判断力的人，写再长的提示词，也只是把自己的混乱放大。

真正值钱的是：

知道问什么；
知道答案哪里不对；
知道怎么验证；
知道怎么交付给真人。

AI 不会替你长脑子。

它只会放大你原来有没有脑子。
```

## Draft 10: Content Is Not Writing

```text
很多人以为做内容就是写作。

不是。

做内容其实是公开争夺解释权。

同一件事：
有人解释成风口。
有人解释成骗局。
有人解释成机会。
有人解释成焦虑。

谁的解释被更多人接受，谁就拿走流量。

所以爆帖不是文笔比赛。

是解释权战争。
```

## Draft 11: The Quiet Paywall

```text
中文互联网很多机会，根本不是被禁止了。

是被支付方式、英语、工具链和信息源悄悄收费了。

你打不开。
你付不了。
你看不懂。
你不知道从哪开始。

最后只能看别人做二道贩子，把英文世界的东西切碎了卖给你。

这不是单纯的信息差。

这是入口税。
```

## Draft 12: More Dangerous Than Not Knowing AI

```text
比不会 AI 更危险的，是半懂 AI。

半懂的人最容易被收割。

看到 Agent 就以为能自动赚钱。
看到 Claude Code 就以为能自动创业。
看到别人晒收入就以为自己缺一个工具。

其实工具只是放大器。

你没有需求判断、产品感、分发能力。

AI 只会帮你更快地制造垃圾。
```
