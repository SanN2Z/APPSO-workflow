# X 平台指令

本文件继承项目根 `AGENTS.md`，并补充 X 专属规则。

- 默认中文；只有用户指定时才写英文或双语。
- 一条内容只承担一个核心观点。优先短、快、有讨论空间，不把公众号段落硬切成推文。
- 热点内容先核发布时间和原始来源；过时信息不能包装成实时新闻。
- 引用帖子时记录原帖 URL、作者、发布时间和截图来源。
- 输出可以包含 2–5 个 hook 版本，但不要制造虚假冲突或假引语。
- 原创观点、事实摘要和 CTA 分开写；CTA 要克制，不能每条都导流。
- X API、价格、限额和自动化规则会变化，使用脚本前必须核查官方文档。
- `scripts/` 中发布相关命令默认 dry-run。真实发帖、回复、点赞、关注或私信必须获得当前任务的明确授权。
- 禁止批量无关回复、自动点赞、群发私信、复制粘贴互动、刷量和规避平台限制。
- 每次真实对外动作都写入 `发布记录/` 或对应内容包的 `publish-record.md`。
