# 视觉与版权规范

## 素材分类

- `原创`：作者或项目自行制作。
- `已授权`：拥有明确授权范围和凭证。
- `AI生成`：记录生成方式，不冒充真实新闻图。
- `官方资料`：产品图、发布页截图或媒体包，保留来源与使用语境。
- `用户提供`：记录提供日期；发布权利仍需用户确认。

## 素材清单

每个内容包的 `asset-manifest.yml` 至少记录：

- `file`
- `used_in_draft`
- `source_type`
- `source`
- `creator_or_rightsholder`
- `obtained_on`
- `modifications`
- `rights_status`
- `allowed_platforms`
- `attribution`

## 使用原则

- 尽量使用原创图表、明确授权素材和可核来源的官方产品图。
- 截图裁切不能改变原意；涉及普通用户时处理头像、昵称和隐私。
- 图表必须能追溯数据来源，不能用视觉比例夸大微小差异。
- 图注保持简短，但来源和关键口径不能省。
- 不确定能否商用时标为 `needs_review`，不推进到 `ready`。

## 默认视觉方向

- 科技内容优先简洁、清楚、移动端可读。
- 封面先保证标题层级和缩略图辨识度，再追求复杂效果。
- 一张图尽量只回答一个问题。

## 当前交付偏好

- 需要 AI 生图或重绘时，优先由 Codex 直接调用 Image2，不再默认只交付 prompt 让用户手动生成。
- 有参考图的「笨拙涂鸦重绘」默认使用 APPSO 内部 Prompt 资产：`APPSO-数字资产/01-栏目与品牌/品牌视觉/生图-Prompt/笨拙涂鸦重绘.md`。
- Image2 必须能访问本轮参考图；若用户提到 attached image 但当前会话没有附件，停止生成并请用户重新附图，不凭描述伪造参考输入。
- 通用生图 prompt 必须写清尺寸、构图、精确文字、视觉风格、禁用元素和裁切安全区；风格化重绘可按已确认的内部 Prompt 执行。
- Image2 产物按 `AI生成` 登记，记录模型、生成日期、输入图来源、必要修改、允许平台和权利状态，并保存到目标内容包 `assets/`。
- 直接生成不等于图片已经可发布；手机端可读性、中文文字、相对路径、输入素材改编权和 manifest 未通过前，稿件不能进入 `ready`。
