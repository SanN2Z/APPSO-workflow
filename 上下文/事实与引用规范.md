# 事实与引用规范

## 来源优先级

1. 官方发布页、官方文档、监管文件、论文原文、当事人原帖。
2. 有方法说明的独立评测、数据库和可信媒体。
3. 二手报道、行业账号和社区讨论，只用于线索或舆情。

## 必须核查的内容

- “最新”、价格、限额、政策、产品状态和榜单。
- 数字、百分比、日期、时区和相隔时间。
- 人物身份、引语、职位和账号归属。
- 跨模型比较中的模型版本、推理档位、工具权限和预算。

## `sources.md` 最小记录

| 字段 | 说明 |
|---|---|
| 来源 | 页面或文件标题 |
| URL/路径 | 直达原始材料 |
| 类型 | 官方 / 第三方 / 媒体 / 社交原帖 / 用户提供 |
| 访问日期 | `YYYY-MM-DD` |
| 支持表述 | 这条来源具体证明什么 |
| 备注 | 口径、限制、待复核项 |

## 表述标签

- **事实**：来源直接支持。
- **厂商自报**：来自参与竞争的公司。
- **第三方结果**：写清评测机构和方法限制。
- **推断**：使用“可能、看起来、更像是”等语言。
- **玩梗/评论**：保留语境，不能冒充事实陈述。

## 发布前复核

时效性事实按 `as_of` 日期重新打开原始页面。页面已更新时，记录变化并同步正文；无法复核时，降低语气或删除。
