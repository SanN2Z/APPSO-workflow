# 运营目标

## 当前阶段

先建立稳定的内容生产与复盘系统，再决定规模化和变现方式。

## 目标层级

1. **质量**：事实准确、语言自然、图片可用、能形成自己的判断。
2. **稳定**：选题、调研、成稿和复盘都有可重复流程。
3. **增长**：找到高质量读者真正愿意转发、收藏和讨论的内容类型。
4. **转化**：在用户确认商业方向后，再设计咨询、产品、社群或其他承接。

## 核心指标

- 内容按期完成率。
- 事实或图片权利问题数。
- 完读、收藏、转发与高质量评论。
- X 的有效关注、主页访问与相关讨论。
- 公众号的阅读完成度、分享和关注转化。
- 能否从复盘中得到下一轮可执行动作。

- 商业承接方式。
