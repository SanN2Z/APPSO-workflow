# 平台差异

| 维度 | X | 微信公众号 |
|---|---|---|
| 核心任务 | 快速表达、加入讨论、验证观点 | 完整叙事、建立信任、沉淀内容 |
| 开头 | 最强观点或最新动作 | 具体人物、冲突、场景或问题 |
| 信息密度 | 一个帖子一个核心点 | 多个证据围绕一条故事线 |
| 篇幅 | 单帖短；thread 分步推进 | 通常 2500–7000 中文字 |
| 配图 | 一眼能懂，适合信息流 | 承担时间线、比较和节奏转换 |
| 来源 | 链接或原帖上下文 | `sources.md` + 正文近邻引用 |
| CTA | 克制地邀请讨论或点击 | 结尾形成判断、收藏或关注理由 |
| 生命周期 | 小时到数天 | 数天到长期搜索与转发 |

跨平台改编先回到同一份 `brief.md` 和 `sources.md`，再按平台重新组织。不要把公众号删短当作 X，也不要把 thread 拼起来当作公众号。
